# 使用技能指南

> 目标：掌握安装 / 删除 skill 的两种方式（前端接口、main.py 代码直调）。本文给出可直接照抄的代码示例。

## 前置条件：安装 skill_hub_sdk 包

本文所有用法都依赖 `skill_hub_sdk` 包，**使用前需先安装**：

```bash
pip install skill_hub_sdk
```

验证安装成功：

```bash
python -c "import skill_hub_sdk; print(skill_hub_sdk.__version__)"
```

> 若提示 `ModuleNotFoundError: No module named 'skill_hub_sdk'`，说明未安装或
> 装在别的 Python 环境（如 venv / 容器内），需在运行服务的那个环境里安装。

---

## 两种方式

| 方式 | 说明 | 适用场景 |
|------|------|----------|
| **方式一：前端调用接口** | 在 `main.py` 注册 hub + 挂载路由，前端通过 HTTP 调 SDK 接口 | Web UI 用户手动安装 / 删除 |
| **方式二：main.py 里代码直接调用** | 在 `main.py` 里调 SDK 的应用服务函数：`install_skills` 安装、`uninstall_skills` 删除 | 启动预装 / 程序化初始化 / 按需卸载 |

方式一（前端）**需要注册 hub**；方式二（代码直调）**无需注册 hub**，函数内部自己实例化 hub。

---

# 方式一：前端调用接口（安装 / 删除）

## 1. `main.py` 注册 hub 并挂载路由

在 `main.py` 里把 `SkillHub` 注册进 `skill_hubs`，并挂载 SDK 提供的 `skill_router`：

```python
from skill_hub_sdk import SkillHub, skill_router as skill_hub_router

app = create_app(
    storage=storage,
    ...
    skill_hubs=[
        ClawSkillHub(api_token=os.getenv("CLAWHUB_API_TOKEN")),  # 可选
        SkillHub(),             # 从 SDK 导入（hub_id 默认 "hf_group3"）
    ],
    ...
)

app.include_router(skill_hub_router)   # 挂载 SDK 提供的前端接口
```

## 2. 前端可用的 SDK 接口（入参）

挂载后，前端通过以下接口浏览、下载、安装、删除 skill。其中「接口 1~3」由 SDK 的 `skill_router` 提供；「接口 4」为 agentscope 框架原本提供的删除接口。

> **公共请求头**：
> - `X-User-ID`（**必填**）—— 当前登录用户 id（如 `zy`）。缺失时框架返回 `401 X-User-ID header is required.`。
> - `guwpToken`（按接口）—— 外部 skillhub 登录 token；不传只能访问「公共 skill」，`/uploaded` 必带。

> **路径前缀**：所有接口统一挂在 **`/api`** 前缀下（`main.py` 中 `root_app.mount("/api", app)`），调用时路径需写完整，例如 `GET /api/workspace/skills/external`。

curl 调用模板（带 `X-User-ID`）：

```bash
HOST=http://localhost:8000
curl -s "$HOST/api/workspace/skills/external?agent_id=<agent_id>&session_id=<session_id>" \
  -H "X-User-ID: admin"
```

### 接口 1：查询外部 skillhub 目录

```
GET /api/workspace/skills/external
```

| 类型 | 参数 | 必填 | 默认 | 说明 |
|------|------|------|------|------|
| Query | `agent_id` | ✅ | - | 目标智能体 id（须属于调用者，否则 404） |
| Query | `session_id` | ✅ | - | 目标会话 id（用于标记 `used` 已装备状态） |
| Query | `page` | - | `0` | 页码，`>=0` |
| Query | `size` | - | `10` | 每页条数，`1~200` |
| Query | `q` | - | `""` | 搜索关键字 |
| Query | `label` | - | `""` | 标签（并入搜索关键字） |
| Query | `sort` | - | `""` | 排序（当前忽略） |
| Header | `X-User-ID` | ✅ | - | 当前登录用户 id |
| Header | `guwpToken` | - | - | 登录 token；不传只能查公共 skill |

### 接口 2：查询当前用户上传的 skill

```
GET /api/workspace/skills/uploaded
```

| 类型 | 参数 | 必填 | 默认 | 说明 |
|------|------|------|------|------|
| Query | `agent_id` | ✅ | - | 目标智能体 id（须属于调用者，否则 404） |
| Query | `session_id` | ✅ | - | 目标会话 id（用于标记 `used`） |
| Query | `page` | - | `0` | 页码，`>=0` |
| Query | `size` | - | `5` | 每页条数，`1~200` |
| Header | `X-User-ID` | ✅ | - | 当前登录用户 id |
| Header | `guwpToken` | ✅ | - | **必带**；缺省返回 400（该接口按用户隔离，需 token 派生远程身份） |

### 接口 3：下载并安装 skill 到 agent

```
POST /api/workspace/skill/download/{name}
```

| 类型 | 参数 | 必填 | 默认 | 说明 |
|------|------|------|------|------|
| Path | `name` | ✅ | - | 技能全名 `命名空间:技能名`，如 `global:write`、`public:writing`（namespace 原样传给远端下载接口） |
| Query | `agent_id` | ✅ | - | 目标智能体 id（须属于调用者，否则 404） |
| Query | `session_id` | ✅ | - | 目标会话 id（安装到该会话绑定的 workspace） |
| Header | `X-User-ID` | ✅ | - | 当前登录用户 id |
| Header | `guwpToken` | - | - | 登录 token；不传只能下载公共 skill |

### 接口 4：从 workspace 删除已安装的 skill（agentscope 框架原本提供）

```
DELETE /api/workspace/skill/{skill_name}
```

| 类型 | 参数 | 必填 | 默认 | 说明 |
|------|------|------|------|------|
| Path | `skill_name` | ✅ | - | 已安装的 skill 名（从会话 workspace 中移除） |
| Query | `agent_id` | ✅ | - | 目标智能体 id |
| Query | `session_id` | ✅ | - | 目标会话 id |
| Header | `X-User-ID` | ✅ | - | 当前登录用户 id |

成功返回 `204 No Content`。对应框架 `WorkspaceBase.remove_skill`，删除该会话 workspace 中指定 skill 的目录并更新索引；与 `install_skills(sync=True)` 的删除行为一致。

## 3. 说明

- **必须注册**：方式一依赖 `skill_hubs=[SkillHub()]` 把 hub 注册进框架，否则接口取不到 hub，返回 `404 No 'hf_group3' skill hub is registered`。
- **路径前缀**：SDK 路由 prefix 固定为 `/workspace`，且 `main.py` 整体挂在 `/api` 下，所以完整路径是 `/api/workspace/...`。两者都不要改动，否则前端路径不匹配。
- **归属校验**：`agent_id` 必须属于（或被共享给）当前 `X-User-ID`，否则返回 404。

# 方式二：main.py 里代码直接调用

不经过 HTTP，在 `main.py` 代码里直接调用 SDK 的应用服务函数，**无需注册 hub**。
包含两个操作：

| 操作 | 函数 | 说明 |
|------|------|------|
| **安装** | `install_skills` | 下载安装 skill，支持对账（删除清单外的） |
| **删除** | `uninstall_skills` | 从 workspace 移除指定 skill（只删清单内的） |

> 两者同属 SDK 的**应用服务层**（`skill_hub_sdk/services/`），负责组合 hub
> 客户端与 workspace 完成编排。SDK 分层为 `services → clients → core`
> （依赖单向），因此从 **`services`** 导入：

```python
from skill_hub_sdk.services import install_skills, uninstall_skills
```

## 1. 调用前准备

需要 4 个标识，**均需你自己获取，无默认值**：

| 参数 | 说明 | 怎么获取 |
|------|------|----------|
| `user_id` | 当前登录用户 id | 请求头 `X-User-ID` |
| `agent_id` | 目标智能体 id | 从智能体列表/会话信息获取 |
| `session_id` | 目标会话 id | 从会话列表/前端 URL 获取 |
| `guwpToken` | 外部 skillhub 登录 token（**仅安装需要**，可选） | 向 GUWP 平台申请 |

> **token 权限限制**：**不传 `guwpToken` 只能下载「公共 skill」**。要下载用户上传/私有的 skill，必须携带 `guwpToken`。删除操作是本地 workspace 操作，不需要 token。

## 2. 安装：install_skills

### 配置驱动（.env 指定 skill，推荐）

**第 1 步：`.env` 里配置要装的 skill**

格式为 **`命名空间:技能名`**（`namespace:name`），逗号分隔可多个：

```bash
BOCOMADP_INSTALL_SKILLS=global:write,public:read     # 命名空间:技能名，逗号分隔，可多个
```

> `namespace` 即远端 skillhub 的命名空间（如 `global` / `public`），下载时会原样传给远端接口；不写命名空间则用默认值（`global`）。

**第 2 步：`main.py` 里导入并调用**

在启动流程的 `_register_builtin_agents()` 之后调用（`workspace_manager` 是 main.py 已有的全局变量）：

```python
from skill_hub_sdk.services import install_skills   # ① 从应用服务层导入

# ② 在启动流程里（_register_builtin_agents 之后）调用
await install_skills(
    workspace_manager,
    user_id="<你的 user_id>",
    agent_id="<你的 agent_id>",
    session_id="<你的 session_id>",
    # guwp_token="<你的 token>",   # 可选；不传只能下载公共 skill
    # sync=True,                   # 可选；True=对账删除多余 skill，False=只装不删
)
```

`.env` 里的 `BOCOMADP_INSTALL_SKILLS` 会被自动读取，无需在代码里写 skill 名。

### 手动指定 skill

不依赖 `.env`，在代码里直接列出要装的 skill：

```python
from skill_hub_sdk.services import install_skills   # ① 从应用服务层导入

# ② 在需要时调用
await install_skills(
    workspace_manager,
    user_id="<你的 user_id>",
    agent_id="<你的 agent_id>",
    session_id="<你的 session_id>",
    skill_names=["global:write", "public:read"],   # 命名空间:技能名，直接指定要装的 skill
    guwp_token="<你的 token>",        # 可选；不传只能下载公共 skill
)
```

### 差量同步（对账）

`install_skills` 每次调用做三向对账：

| 情形 | 行为 |
|------|------|
| 期望有、现有无 | 下载安装 |
| 期望有、现有有 | 跳过（不重复装） |
| 现有有、期望无 | `sync=True`（默认）时**删除**；`sync=False` 时保留 |

例如：第一次配置 `read,write`，第二次只配置 `read` → 自动**删除多余的 `write`**。

> **注意**：删除不可逆。确保期望列表完整，漏配的 skill 会被 `sync=True` 误删；不确定时可先 `sync=False`。
>
> 如果只是想**卸掉某几个 skill**（而不是固定成某份清单），请用下面的
> **`uninstall_skills`**——它只删清单内的，清单外的完全不受影响，更安全。

## 3. 删除：uninstall_skills

### 与 install_skills(sync=True) 怎么选

| 函数 | 语义 | 清单外的 skill |
|------|------|----------------|
| **`uninstall_skills`** | 按需卸载，删除**清单内**的 | **不受影响** ✅ |
| `install_skills(sync=True)` | 全量同步，删除**清单外**的 | 被删除（对账） |

简单说：**想卸掉某几个 skill → 用 `uninstall_skills`；要把 skill 固定成某份清单 → 用 `install_skills(sync=True)`**。

### main.py 里怎么写

```python
from skill_hub_sdk.services import uninstall_skills   # ① 从应用服务层导入

# ② 在需要时调用
await uninstall_skills(
    workspace_manager,
    user_id="<你的 user_id>",
    agent_id="<你的 agent_id>",
    session_id="<你的 session_id>",
    skill_names=["global:read"],   # 命名空间:技能名，直接指定要删的 skill
)
```

`skill_names` 为**必填**（不传则直接跳过，不删除任何 skill）。格式为
**`命名空间:技能名`**；也支持不带命名空间的裸名（如 `read`），workspace 内按
agent-facing name 匹配。

### 返回值与行为

返回 `{"removed": [...], "skipped": [...]}`：

| 情形 | 行为 |
|------|------|
| 清单内的 skill 已装备 | **删除**，记入 `removed` |
| 清单内的 skill 未装备 | 跳过，记入 `skipped`（**不报错**，幂等） |
| 清单外的 skill | **不受影响**（不会被删） |
| 未传 `skill_names`（或传空列表） | **直接跳过，不删除任何 skill** |

> **安全设计**：清单为空时不会误删。这是与 `install_skills(sync=True)` 最大的区别——后者空清单会把所有 skill 删光。

## 4. 装到 / 删到哪个位置（作用域）

**skill 是给「智能体」安装的**，作用域是「**user_id + agent_id**」。

`session_id` **不是占位符，是定位 workspace 的必要参数**——后端要通过它解析出该会话绑定的 workspace（`get_workspace(user_id, agent_id, session_id)`），进而定位到 agent 级共享 PVC 下的 skills 目录。后端通过 **shared PVC** 把同一智能体（`agent_id`）的 skills 目录共享给该智能体的**所有会话**：

- 同一 `agent_id` 下，**不同会话共享同一份 skill**，装一次即可，无需每个会话重装。
- 但每次调用仍**必须传入正确的 `session_id`**（它定位了操作的 workspace），只是底层目录在 agent 级 PVC 上是共享的。
- 换一个**新的智能体**（`agent_id` 不同）才需要重新操作。
- 删除同理：删掉后该智能体的**所有会话**都不再有该 skill。

# 附：环境变量

| 变量 | 说明 |
|------|------|

| `BOCOMADP_INSTALL_SKILLS` | 逗号分隔的要预装 skill 名，格式 `命名空间:技能名`（如 `global:write`）；留空不预装 |

# 附：排障速查

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| `ModuleNotFoundError: No module named 'skill_hub_sdk'` | 包未安装 / 装错环境 | `pip install skill_hub_sdk`；确认装在**运行服务**的那个 Python 环境（venv / 容器）里 |
| 方式一接口 404 `No 'hf_group3' skill hub` | 未注册 hub | 确认 `skill_hubs` 里加了 `SkillHub()` |
| 方式一前端 404 | 路径少了 `/api` / prefix 被改 | 用完整路径 `/api/workspace/...`；保持 prefix 不变 |
| 报 skill not found | skill 名不存在 | 确认拼写、确认在远端目录中 |
| 能查目录但下载失败 | token 无/无效 | 带有效的 `guwpToken` |
| 装完没生效 | `agent_id` 填错 / 新智能体 | 确认 `agent_id` 一致（同一智能体会话共享）；换新智能体才需重装 |
| `install_skills` 导入失败 | 导入路径不对 / SDK 未导入 | 用 `from skill_hub_sdk.services import install_skills`（应用服务层） |
| `uninstall_skills` 导入失败 | 导入路径不对 / SDK 未导入 | 用 `from skill_hub_sdk.services import uninstall_skills`（应用服务层） |
| `SkillHub` 导入失败 | SDK 未导入 | 用 `from skill_hub_sdk import SkillHub` |
| 删了 skill 但目录 `used` 仍为 true | 未刷新 / 装到了别的智能体 | 重新查询；确认 `agent_id` 一致（shared PVC 按 agent 共享） |
| `install_skills` 把不该删的删了 | 用成了 `sync=True` 对账 | 只想卸某几个改用 `uninstall_skills`；或先 `sync=False` |
