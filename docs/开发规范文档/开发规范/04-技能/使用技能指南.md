# 使用技能指南

> 目标：掌握安装 skill 的两种方式。本文给出可直接照抄的代码示例。

安装 skill 有两种方式，选择其一即可：

| 方式 | 说明 | 适用场景 |
|------|------|----------|
| **方式一：前端调用接口** | 在 `main.py` 注册 hub + 挂载路由，前端通过 HTTP 调 SDK 接口安装 | Web UI 用户手动安装 |
| **方式二：main.py 直接安装** | 在 `main.py` 里调用 SDK 的 `install_skills` 直接安装 | 启动预装 / 程序化初始化 |

---

# 方式一：前端调用接口安装

## 1. `main.py` 注册 hub 并挂载路由

在 `main.py` 里把 `ExternalSkillHub` 注册进 `skill_hubs`，并挂载 SDK 提供的 `external_skill_router`：

```python
from external_hub_sdk import ExternalSkillHub, external_skill_router

app = create_app(
    storage=storage,
    ...
    skill_hubs=[
        ClawSkillHub(api_token=os.getenv("CLAWHUB_API_TOKEN")),  # 可选
        ExternalSkillHub(),             # 从 SDK 导入，行为不变
    ],
    ...
)

app.include_router(external_skill_router)   # 挂载 SDK 提供的前端接口
```

## 2. 前端可用的 SDK 接口（入参）

挂载后，前端通过以下接口浏览、下载、安装、删除 skill。其中「接口 1~3」由 SDK 的 `external_skill_router` 提供；「接口 4」为 agentscope 框架原本提供的删除接口。

> **公共请求头**：
> - `X-User-ID`（必填）—— 当前登录用户 id。
> - `guwpToken`（按接口）—— 外部 skillhub 登录 token；不传只能访问「公共 skill」，`/uploaded` 必带。

### 接口 1：查询外部 skillhub 目录

```
GET /workspace/skills/external
```

| 类型 | 参数 | 必填 | 默认 | 说明 |
|------|------|------|------|------|
| Query | `agent_id` | ✅ | - | 目标智能体 id（须属于调用者，否则 404） |
| Query | `session_id` | ✅ | - | 目标会话 id（用于标记 `used` 已装备状态） |
| Query | `page` | - | `0` | 页码，`>=0` |
| Query | `size` | - | `10` | 每页条数，`1~200` |
| Query | `q` | - | `""` | 搜索关键字 |
| Query | `label` | - | `""` | 标签（并入搜索关键字） |
| Query | `sort` | - | `""` | 排序（当前忽略） |
| Header | `guwpToken` | - | - | 登录 token；不传只能查公共 skill |

### 接口 2：查询当前用户上传的 skill

```
GET /workspace/skills/uploaded
```

| 类型 | 参数 | 必填 | 默认 | 说明 |
|------|------|------|------|------|
| Query | `agent_id` | ✅ | - | 目标智能体 id（须属于调用者，否则 404） |
| Query | `session_id` | ✅ | - | 目标会话 id（用于标记 `used`） |
| Query | `page` | - | `0` | 页码，`>=0` |
| Query | `size` | - | `5` | 每页条数，`1~200` |
| Header | `guwpToken` | ✅ | - | **必带**；缺省返回 400（该接口按用户隔离，需 token 派生远程身份） |

### 接口 3：下载并安装 skill 到 agent

```
POST /workspace/skill/download/{name}
```

| 类型 | 参数 | 必填 | 默认 | 说明 |
|------|------|------|------|------|
| Path | `name` | ✅ | - | 技能全名 `category:name`，如 `public:writing`（仅 `public` 可下载） |
| Query | `agent_id` | ✅ | - | 目标智能体 id（须属于调用者，否则 404） |
| Query | `session_id` | ✅ | - | 目标会话 id（安装到该会话绑定的 workspace） |
| Header | `guwpToken` | - | - | 登录 token；不传只能下载公共 skill |

### 接口 4：从 workspace 删除已安装的 skill（agentscope 框架原本提供）

```
DELETE /workspace/skill/{skill_name}
```

| 类型 | 参数 | 必填 | 默认 | 说明 |
|------|------|------|------|------|
| Path | `skill_name` | ✅ | - | 已安装的 skill 名（从会话 workspace 中移除） |
| Query | `agent_id` | ✅ | - | 目标智能体 id |
| Query | `session_id` | ✅ | - | 目标会话 id |
| Header | `X-User-ID` | ✅ | - | 当前登录用户 id |

成功返回 `204 No Content`。对应框架 `WorkspaceBase.remove_skill`，删除该会话 workspace 中指定 skill 的目录并更新索引；与 `install_skills(sync=True)` 的删除行为一致。

## 3. 说明

- **必须注册**：方式一依赖 `skill_hubs=[ExternalSkillHub()]` 把 hub 注册进框架，否则接口取不到 hub，返回 `404 No 'external' skill hub is registered`。
- **`external_skill_router` 的 prefix 固定为 `/workspace`**，不要改动，否则前端路径不匹配。
- **归属校验**：`agent_id` 必须属于（或被共享给）当前 `X-User-ID`，否则返回 404。

# 方式二：main.py 里直接安装

不经过 HTTP，在 `main.py` 代码里直接调用 SDK 的 `install_skills` 安装，**无需注册 hub**。

## 1. 安装前准备

安装需要 4 个标识，**均需你自己获取，无默认值**：

| 参数 | 说明 | 怎么获取 |
|------|------|----------|
| `user_id` | 当前登录用户 id | 请求头 `X-User-ID` |
| `agent_id` | 目标智能体 id | 从智能体列表/会话信息获取 |
| `session_id` | 目标会话 id | 从会话列表/前端 URL 获取 |
| `guwpToken` | 外部 skillhub 登录 token（可选） | 向 GUWP 平台申请 |

> **token 权限限制**：**不传 `guwpToken` 只能下载「公共 skill」**。要下载用户上传/私有的 skill，必须携带 `guwpToken`。

## 2. main.py 里怎么写

你要在 `main.py` 里做两件事：**① 导入 `install_skills`，② 在启动流程里调用**。

### 配置驱动（.env 指定 skill，推荐）

**第 1 步：`.env` 里配置要装的 skill**

```bash
BOCOMADP_INSTALL_SKILLS=global:write,public:read     # 逗号分隔，可多个
```

**第 2 步：`main.py` 里导入并调用**

在启动流程的 `_register_builtin_agents()` 之后调用（`workspace_manager` 是 main.py 已有的全局变量）：

```python
from external_hub_sdk import install_skills   # ① 导入

# ② 在启动流程里（_register_builtin_agents 之后）调用
await install_skills(
    workspace_manager,
    user_id="<你的 user_id>",
    agent_id="<你的 agent_id>",
    session_id="<你的 session_id>",
    # guwp_token="<你的 token>",   # 可选；不传只能下载公共 skill
    # sync=True,                   # 可选；True=对账删除多余 skill，False=只装不删
)
```

`.env` 里的 `BOCOMADP_INSTALL_SKILLS` 会被自动读取，无需在代码里写 skill 名。

### 手动指定 skill

不依赖 `.env`，在代码里直接列出要装的 skill：

```python
from external_hub_sdk import install_skills   # ① 导入

# ② 在需要时调用
await install_skills(
    workspace_manager,
    user_id="<你的 user_id>",
    agent_id="<你的 agent_id>",
    session_id="<你的 session_id>",
    skill_names=["gloabl:write", "public:read"],   # 直接指定要装的 skill
    guwp_token="<你的 token>",        # 可选；不传只能下载公共 skill
)
```

## 3. 差量同步（对账）

`install_skills` 每次调用做三向对账：

| 情形 | 行为 |
|------|------|
| 期望有、现有无 | 下载安装 |
| 期望有、现有有 | 跳过（不重复装） |
| 现有有、期望无 | `sync=True`（默认）时**删除**；`sync=False` 时保留 |

例如：第一次配置 `read,write`，第二次只配置 `read` → 自动**删除多余的 `write`**。

> **注意**：删除不可逆。确保期望列表完整，漏配的 skill 会被 `sync=True` 误删；不确定时可先 `sync=False`。

## 4. 安装到哪个位置（作用域）

**skill 是给「智能体」安装的**，作用域是「**user_id + agent_id**」。

`session_id` **不是占位符，是定位 workspace 的必要参数**——后端要通过它解析出该会话绑定的 workspace（`get_workspace(user_id, agent_id, session_id)`），进而定位到 agent 级共享 PVC 下的 skills 目录。后端通过 **shared PVC** 把同一智能体（`agent_id`）的 skills 目录共享给该智能体的**所有会话**：

- 同一 `agent_id` 下，**不同会话共享同一份 skill**，装一次即可，无需每个会话重装。
- 但每次安装仍**必须传入正确的 `session_id`**（它定位了写入的 workspace），只是底层目录在 agent 级 PVC 上是共享的。
- 换一个**新的智能体**（`agent_id` 不同）才需要重新安装。

# 附：环境变量

| 变量 | 说明 |
|------|------|
| `BOCOMADP_EXTERNAL_SKILLHUB_URL` | 外部 skillhub 服务地址；未配置用默认地址 |
| `BOCOMADP_INSTALL_SKILLS` | 逗号分隔的要预装 skill 名（方式二配置驱动使用）；留空不预装 |

# 附：排障速查

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 方式一接口 404 `No 'external' skill hub` | 未注册 hub | 确认 `skill_hubs` 里加了 `ExternalSkillHub()` |
| 方式一前端 404 | prefix 被改 | 保持 `/workspace` |
| 报 skill not found | skill 名不存在 | 确认拼写、确认在远端目录中 |
| 能查目录但下载失败 | token 无/无效 | 带有效的 `guwpToken` |
| 装完没生效 | `agent_id` 填错 / 新智能体 | 确认 `agent_id` 一致（同一智能体会话共享）；换新智能体才需重装 |
| `install_skills` / `ExternalSkillHub` 导入失败 | SDK 未导入 | 确认已安装/导入 `external_hub_sdk`（`from external_hub_sdk import ...`） |
