# 使用技能指南

> 目标：掌握两种安装技能的方式——**前端调用接口安装** 与 **main.py 里直接安装**。

## 一、技能（Skill）是什么

技能是一组可被智能体调用的、自包含的能力包。每个技能包含一个 `SKILL.md`（`name` + `description`）以及对应的实现文件。技能通过 **skill hub** 提供：hub 负责目录查询与下载，把技能归档安装进某个 agent 的 workspace。

AgentScope 通过 `SkillHubBase` 抽象统一管理各类 hub，`create_app(skill_hubs=[...])` 把 hub 注册进框架。

安装技能有两种方式：

| 方式 | 触发来源 | 依赖 | 适用场景 |
|------|----------|------|----------|
| 前端调用接口 | HTTP 端点 `POST /workspace/skill/download/{name}` | 必须注册 hub | Web UI 用户手动安装 |
| main.py 直接安装 | 后端代码直接调用 | 不依赖注册表 | 启动预装 / 定时 / 程序化初始化 |

## 二、前端调用接口安装

### 1. 前置：注册 external skill hub

接口安装**必须**在 `create_app(skill_hubs=[...])` 里注册 `ExternalSkillHub()`，否则路由从注册表取不到 `"external"` 这个 hub，直接返回 `404 No 'external' skill hub is registered`。

> ⚠️ 前置条件：SDK 模块（`bocomadp/external_hub_sdk/`，含 `core/`、`clients/`、`routers/`）需先按 `docs/external-hub-sdk-design.md` 落地。

#### SDK 结构

```
bocomadp/external_hub_sdk/
├── __init__.py          # 导出 ExternalSkillHub + external_skill_router
├── core/                # base.py(SkillHubClientBase) / models.py / errors.py
├── clients/             # external.py(ExternalSkillHub)
└── routers/             # deps.py / schema.py / external.py(external_skill_router)
```

SDK 对外暴露两个符号：`ExternalSkillHub`（hub 类）与 `external_skill_router`（路由）。它不依赖 bocomadp 其他业务模块（除框架 `agentscope.app.deps` / `HubError`），可移植到其他工程。

#### 在 `main.py` 里接入（三步）

**第 1 步：导入**

```python
from bocomadp.external_hub_sdk import ExternalSkillHub, external_skill_router
```

**第 2 步：装配进 `skill_hubs`**

```python
app = create_app(
    storage=storage,
    ...
    mcp_hubs=[GitHubMCPHub()],
    skill_hubs=[
        ClawSkillHub(api_token=os.getenv("CLAWHUB_API_TOKEN")),  # 可选
        ExternalSkillHub(),          # ← 必须，接口安装依赖它
    ],
    ...
)
```

`ExternalSkillHub()` 构造无需额外参数：`base_url` 从环境变量 `BOCOMADP_EXTERNAL_SKILLHUB_URL` 读取（未配置时回落默认地址）。`guwpToken` 由每个请求逐请求注入，装配时无需设置。

**第 3 步：挂载路由**

```python
app.include_router(external_skill_router)
```

> `external_skill_router` 的 `prefix` 固定为 `/workspace`，与前端约定一致，**不要改动**，否则前端路径 404。

### 2. 端点一览

| 方法 | 路径 | 说明 |
|------|------|------|
| GET  | `/workspace/skills/external` | 查询外部 skillhub 目录 |
| GET  | `/workspace/skills/uploaded` | 当前用户上传的 skill |
| POST | `/workspace/skill/download/{name}` | 下载并安装到 agent 的 workspace |

调用时需携带：
- `X-User-ID` 请求头 —— 用户标识（`get_current_user_id` 依赖）。
- `agent_id`、`session_id` 查询参数 —— 定位目标 workspace（PER_SESSION 语义下从会话记录解析）。
- `guwpToken` 请求头 —— 外部 skillhub 的登录 token（上传列表必带，目录/下载按需）。

### 3. 安装链路

`POST /workspace/skill/download/{name}` 的完整处理：

1. 校验 `skill_full_name` 为 `category:name` 形式（仅 `public` 可下载）。
2. 从会话记录解析目标 workspace（`storage.get_session` → `config.workspace_id`，PER_SESSION 下精确）。
3. 若已装备则幂等返回。
4. 经 `hub.download()` 拿到归档流，`workspace.add_skill_archive()` 流式安装。
5. 校验确有新 skill 落盘（含合法 `SKILL.md`）。

示例调用：

```bash
curl -X POST "http://localhost:8000/workspace/skill/download/public:writing" \
  -H "X-User-ID: alice" \
  -H "guwpToken: <token>" \
  "?agent_id=<agent_id>&session_id=<session_id>"
```

## 三、main.py 里直接安装

不经过 HTTP，在 `main.py` 代码里直接下载并安装。本质三步：**取 workspace → hub 下载 → 装入 workspace**。

### 1. 前置：无需注册 hub

这种方式是**自己实例化** `ExternalSkillHub()`，不依赖 `create_app` 的注册表，因此**不需要**在 `skill_hubs=[...]` 里注册。

### 2. 代码示例

```python
# main.py —— 全局单例（workspace_manager、storage）就绪后可调用
from bocomadp.external_hub_sdk import ExternalSkillHub


async def install_skill_via_code(
    user_id: str,
    agent_id: str,
    session_id: str,
    skill_name: str,
    guwp_token: str | None = None,
) -> None:
    """直接通过代码把外部 skill 下载并安装进 agent 的 workspace。"""
    # 1) 解析该会话绑定的 workspace（PER_SESSION 语义，须从会话记录解析）
    workspace = await workspace_manager.get_workspace(
        user_id,
        agent_id,
        session_id,
    )

    hub = ExternalSkillHub()
    hub.set_token(guwp_token)          # 外部 hub 需 token 换 SESSION cookie
    try:
        # 2) 幂等：已在 workspace 则跳过
        existing = await workspace.list_skills()
        if skill_name in {s.name for s in existing}:
            return

        # 3) 下载归档（惰性流）+ 安装
        archive = await hub.download(user_id, skill_name)
        await workspace.add_skill_archive(
            archive.stream,
            archive.format,
            skill_name,
        )
    except KeyError:
        raise RuntimeError(f"Skill '{skill_name}' not found on remote hub.") from None
```

### 3. 调用时机

- **启动预装**：在 `main.py` 的 `_lifespan_with_builtin_agents` 里、`_register_builtin_agents()` 之后调用。此时无具体 `user_id / agent_id / session_id`，需自行确定目标（如给默认用户、内置 agent 装默认技能）。
- **程序化初始化 / 定时任务**：拿到具体会话后调用。

### 4. 关键点说明

| 点 | 说明 |
|----|------|
| workspace 绑定 | `get_workspace(user_id, agent_id, session_id)`；PER_SESSION 隔离下应仿照路由用 `storage.get_session()` 拿到 `config.workspace_id` 再传第 4 参 |
| token 必须 | 外部 hub 下载端点需带 cookie；无 token 走匿名会话通常被远端拒绝 |
| 幂等检查 | 先 `workspace.list_skills()` 判断是否已装，避免重复下载 |
| `SkillArchive` | 是 `NamedTuple(format, stream)`，`stream` 为惰性异步迭代器，直接喂给 `add_skill_archive` 流式安装，不占内存 |

---

## 四、环境变量

| 变量 | 说明 |
|------|------|
| `BOCOMADP_EXTERNAL_SKILLHUB_URL` | 外部 skillhub 服务地址；未配置时回落到 `DEFAULT_BASE_URL`（见 `clients/external.py`） |

## 五、注意事项

1. **不要把 hub 当请求上下文用**：装配阶段没有当前用户，`guwpToken` 必须由路由层逐请求通过 `set_token()` 注入，hub 装配时保持无 token 状态。
2. **prefix 不要改**：`external_skill_router` 必须保持 `/workspace`，否则前端调用路径不匹配。
3. **响应模型统一**：路由用到的 `SkillInfo` / `AgentSkillsListResponse` / `SkillActionResponse` 统一从 `skills/_schema.py` 导入（或 SDK 的 `schema.py` re-export 同一份），避免同字段不同类导致序列化差异。
4. **错误统一为 `HubError`**：SDK 的 `core/errors.py` 依赖 agentscope 的 `HubError`，调用方捕获 `HubError` 即可统一处理。
5. **迁移复用**：SDK 目录自包含，拷贝到其他工程后在目标 `main.py` 做同样三步即可接入。

## 六、排障速查

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| `GET /workspace/skills/external` 404 | hub 未注册 | 确认 `skill_hubs` 里加了 `ExternalSkillHub()` |
| `404 No 'external' skill hub is registered` | `hub_id` 不匹配 | 确认 SDK 路由取的是 `hubs["external"]` |
| 目录能查但下载失败 | token 未传 / 无权限 | 带 `guwpToken` 请求头 |
| 前端 404 | prefix 被改 | 保持 `/workspace` |
| 代码安装抛 `KeyError` | 远端无该 skill | 确认 `skill_name` 在目录中存在 |
