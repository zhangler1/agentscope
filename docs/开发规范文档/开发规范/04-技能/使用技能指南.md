# 使用技能指南

> 目标：会写 SKILL.md、会注册技能、理解两阶段加载机制。

技能（Skill）是一个包含 `SKILL.md` 的文件夹，告诉智能体**如何完成某类任务**（可附带脚本与资源）。与工具的区别：工具是「一个可调用的函数」，技能是「一套完整的做法」（多步骤流程 + 示例 + 脚本用法）。

## SKILL.md 编写规范

`SKILL.md` 由 **frontmatter（元数据）+ 正文（指令）** 构成：

```markdown
---
name: web-search
description: 使用搜索引擎检索信息并提炼结果，适合需要最新资讯的任务
---

# 网络搜索技能

## 使用步骤
1. 调用 web_search 工具，构造精确的关键词
2. 对前 3 条结果调用 fetch 获取正文
3. 交叉比对信息，标注来源链接

## 注意事项
- 检索结果需注明发布日期
- 优先采信官方来源
```

frontmatter 字段：

| 字段          | 必填 | 说明                                       |
| ------------- | ---- | ------------------------------------------ |
| `name`        | 是   | 技能标识（全局唯一）                       |
| `description` | 是   | 一句话说明适用场景——**写好它，智能体靠它决定何时用这个技能** |

正文是给智能体看的完整指令：步骤、约束、示例、附带脚本（如 `scripts/run.py`）的调用方式都写在这里。

目录结构示例：

```text
skills/
└── web-search/
    ├── SKILL.md          # 必须，位于根目录
    ├── scripts/
    │   └── extract.py    # 可选：技能附带的脚本
    └── templates/
        └── report.md     # 可选：技能附带的资源
```

## 两阶段加载

技能以**两阶段**方式工作，避免撑爆系统提示词：

1. **注册阶段**：只把每个技能的 `name` 与 `description`（来自 frontmatter）注入系统提示——智能体知道自己"会什么"；
2. **查看阶段**：智能体决定使用某技能时，才加载 `SKILL.md` 完整正文（含步骤、示例、脚本用法）。

这意味着你可以放心注册几十个技能而不担心上下文膨胀，代价只是 description 的几十个 token。

## 注册技能

```python
from agentscope.tool import LocalSkillLoader, Toolkit

toolkit = Toolkit(
    # 方式一：直接传技能目录路径（多个）
    skills_or_loaders=["./skills/web-search"],
    # 方式二：目录扫描加载器（自动发现子目录中的技能）
    # skills_or_loaders=LocalSkillLoader(path="./skills", scan_subdir=True),
)

agent = Agent(name="Friday", model=model, toolkit=toolkit)
```

`LocalSkillLoader` 支持基于目录的技能加载与监听（技能文件变更自动生效），也支持从 sandbox / web 即时加载。

## 技能与工具组

技能本质会被打包为 `ToolGroup`，可随工具组机制按需激活（见 [使用工具指南 · 工具组](../03-工具-mcp-cli/使用工具指南.md#工具组与元工具-reset_tools)）——注册很多技能时，可按任务阶段分组，避免智能体同时面对过多选项。

## 技能来源

- **本地目录**：如上注册，适合自研技能；
- **技能中心**：生产环境从 ClawHub 等目录安装他人发布的技能（安装到用户资源池，再装配给智能体工作区），见部署规范 [对接微应用](../../部署规范/对接微应用.md)；
- **本地上传**：包含 `SKILL.md` 的文件夹直接上传到工作区。

## 编写好技能的清单

- [ ] `description` 写清**何时该用**（而不是它是什么）；
- [ ] 步骤可执行：每一步对应智能体实际可做的动作（调用工具、读文件）；
- [ ] 附带脚本时给出确切调用方式（命令行、参数、输出格式）；
- [ ] 写明失败兜底（检索为空怎么办、脚本报错怎么办）；
- [ ] 一个技能只做一类事——过大的技能拆成多个。
