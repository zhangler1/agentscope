# 配置项

> 目标：给出一个**把常用配置全部用上的完整 demo**，并提供全部可调配置项的速查表——新工程从这里复制起步。

## 全配置 Demo

```python
import asyncio
import os

from agentscope.agent import Agent
from agentscope.context import ContextConfig, InjectionConfig
from agentscope.credential import DashScopeCredential
from agentscope.message import UserMsg
from agentscope.middleware import (
    ReplyBudgetControlMiddleware,
    TracingMiddleware,
)
from agentscope.model import DashScopeChatModel
from agentscope.permission import PermissionContext, PermissionMode, PermissionRule
from agentscope.tool import Bash, Edit, Glob, Grep, Read, Toolkit, Write
from agentscope.workspace import LocalWorkspace


async def main() -> None:
    # ① 工作区：工具执行环境（见 ../06-安全/沙箱.md）
    ws = LocalWorkspace(workdir="./data/project")
    await ws.initialize()

    # ② 模型：凭证 + 模型类两层结构（见 ../02-参考文档/模型层.md）
    model = DashScopeChatModel(
        credential=DashScopeCredential(api_key=os.environ["DASHSCOPE_API_KEY"]),
        model="qwen3.7-max",
    )

    # ③ 工具箱：工具 + MCP + 技能（见 ../03-工具-mcp-cli/使用工具指南.md）
    toolkit = Toolkit(tools=[Bash(), Read(), Write(), Edit(), Glob(), Grep()])

    # ④ 长期记忆:集成记忆包(见 ../05-记忆/会话记忆能力使用规范.md)
    from bocomadp.memory import build_memory_middlewares, install_memory

    async def _build_agent_middlewares(user_id, agent_id, session_id):
        mws = []                                    # 已有的中间件链
        mws.extend(
            await build_memory_middlewares(user_id, agent_id, session_id)
        )
        return mws

    # 服务化部署时:
    #   app = create_app(..., extra_agent_middlewares=_build_agent_middlewares)
    #   install_memory(app)                          # 注册记忆配置路由
    #   之后通过 PUT /api/memory/config/{agent_id} 开启记忆(memory_enabled=true)

    # ⑤ 智能体：全部常用配置一次到位
    agent = Agent(
        name="Friday",
        system_prompt="你是一个严谨的开发助手。",
        model=model,
        toolkit=toolkit,
        offloader=ws,                                        # 上下文卸载
        middlewares=[
            TracingMiddleware(),                             # 最外层：全链路追踪
            ReplyBudgetControlMiddleware(max_budget=200_000),
        ],
        # 上下文窗口策略
        context_config=ContextConfig(
            trigger_ratio=0.8,
            reserve_ratio=0.5,
            tool_result_limit=5,
            max_image_num=2,
        ),
        # 运行时状态注入
        injection_config=InjectionConfig(
            inject_time=True,
            inject_tasks=True,
            inject_context_usage=True,
            extra_fields={"project": "my-app"},
        ),
        # 权限
        permission_context=PermissionContext(
            mode=PermissionMode.ACCEPT_EDITS,
            deny_rules=[
                PermissionRule(tool_name="Bash", rule_content="rm -rf*", behavior="deny"),
                PermissionRule(tool_name="Bash", rule_content="sudo *", behavior="deny"),
            ],
        ),
    )

    msg = await agent.reply(UserMsg("user", "梳理当前目录结构并总结"))
    print(msg.get_text_content())

    await ws.close()


asyncio.run(main())
```

## ContextConfig：上下文窗口策略

| 参数               | 默认行为说明                                         |
| ------------------ | ---------------------------------------------------- |
| `trigger_ratio`    | 上下文占用超过窗口该比例时触发自动压缩（示例 0.8）   |
| `reserve_ratio`    | 压缩后保留约该比例空间给新内容（示例 0.5）           |
| `tool_result_limit`| 每个工具最多保留最近 N 条结果                        |
| `max_image_num`    | 上下文中最多保留 N 张图片                            |

自动压缩五步：检查占用 → 超阈值触发 → 生成结构化摘要（已完成任务/当前任务/关键发现/待办/环境）→ 摘要替换旧消息、保留最近若干轮 → 超限内容以 `<<<TRUNCATED>>>` 占位（配合 offloader 可取回）。

## InjectionConfig：运行时注入

| 参数                   | 说明                                                 |
| ---------------------- | ---------------------------------------------------- |
| `inject_time`          | 注入当前时间                                         |
| `inject_tasks`         | 注入未完成任务提醒                                   |
| `inject_context_usage` | 注入上下文用量（提醒智能体节约）                     |
| `extra_fields`         | 自定义键值（业务上下文）                             |
| `template`             | 自定义模板，**必须包含 `{runtime_state}` 占位符**，否则构造时报错 |

## 服务级配置：create_app 参数

把 demo 服务化为多租户 HTTP 服务时（见 [CICD 集成](../../部署规范/CICD集成.md)）：

| 参数                       | 类型 / 默认                            | 说明                                                         |
| -------------------------- | -------------------------------------- | ------------------------------------------------------------ |
| `storage`                  | `StorageBase`，必填                    | 持久化层（`RedisStorage` / `AsyncSQLAlchemyStorage`）       |
| `message_bus`              | `MessageBus`，必填                     | 会话锁/回放/收件箱/唤醒，多进程部署的关键                    |
| `workspace_manager`        | `WorkspaceManagerBase`，必填           | 工作区生命周期管理                                           |
| `knowledge_base_manager`   | `None`                                 | 传入后启用 `/knowledge_bases` 全部端点                       |
| `knowledge_parsers`        | `[TextParser()]`                       | 上传链路解析器                                               |
| `knowledge_chunkers`       | `[ApproxTokenChunker]`                 | 可选切块器类                                                 |
| `blob_store`               | `LocalBlobStore('./blobs')`            | 上传文件对象存储；分布式须用 S3 等共享后端                   |
| `enable_index_worker`      | `True`                                 | 单进程模式；`False` 时索引交给独立 worker                    |
| `extra_credentials`        | `None`                                 | 注册自定义凭证类型                                           |
| `extra_middlewares`        | `None`                                 | ASGI/协议层中间件（如 `AGUIProtocolMiddleware`）             |
| `extra_agent_middlewares`  | `None`                                 | 追加到每个智能体的中间件                                     |
| `extra_agent_tools`        | `None`                                 | 追加到每个智能体的工具                                       |
| `custom_subagent_templates`| `None`                                 | 团队子智能体模板                                             |
| `custom_agent_cls`         | `None`                                 | 替换智能体类（默认 `Agent`）                                 |
| `mcp_hubs` / `skill_hubs`  | `None`                                 | MCP/技能中心                                                 |
| `channels`                 | `None`                                 | IM 渠道类型                                                  |
| `resource_access_policy`   | 默认拒绝一切跨用户共享                 | 资源共享策略                                                 |

## 配置分层建议

| 配置类别     | 放哪                                 | 理由                                   |
| ------------ | ------------------------------------ | -------------------------------------- |
| 密钥凭证     | 环境变量 / 服务的凭证管理            | 脱敏要求，见 [数据识别和脱敏](../06-安全/数据识别和脱敏.md) |
| 业务参数     | 代码内显式构造                       | 类型安全、可调试                       |
| 环境差异     | 环境变量 + 启动脚本                  | 同一代码多环境部署                     |
| 运行时可变   | `agent.state` / REST API             | 运行时切换（如权限模式收紧）           |

> **提示**：权限模式可在运行时切换——`agent.state.permission_context.mode = PermissionMode.EXPLORE`，无需重建智能体。
