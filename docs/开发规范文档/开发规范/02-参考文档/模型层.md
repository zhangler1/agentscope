# 模型层

> 目标：会切换模型提供商、会直接调用模型、会自定义接入公司内部/未适配的模型 API。

模型层采用**两层结构**：**凭证（Credential）** 负责密钥管理与验证，**模型类** 负责 API 调用与协议适配。二者解耦后，凭证可独立管理、枚举模型，模型类可与任意凭证实例组合。

## 凭证与模型族矩阵

| 凭证类                | 支持的模型族                        |
| --------------------- | ----------------------------------- |
| `DashScopeCredential` | 阿里云百炼（Qwen 系列）             |
| `OpenAICredential`    | OpenAI（GPT 系列、兼容端点）        |
| `AnthropicCredential` | Anthropic（Claude 系列）            |
| `GeminiCredential`    | Google（Gemini 系列）               |
| `DeepSeekCredential`  | DeepSeek                            |
| `KimiCredential`      | Moonshot / Kimi                     |
| `XAICredential`       | xAI（Grok 系列）                    |
| `OllamaCredential`    | Ollama（本地模型，无需密钥）        |

凭证通过 `api_key` 参数或环境变量构造，`await credential.verify()` 可验证有效性。

## 模型卡片（ModelCard）

每种模型类型有声明式卡片（YAML/Python），描述身份、能力与参数约束：

| 卡片字段（共享）      | 说明                                  |
| --------------------- | ------------------------------------- |
| `model`               | 模型标识（如 `qwen3.7-max`）          |
| `display_name`        | 前端展示名                            |
| `provider`            | 提供商                                |
| `input_types`         | 支持的输入类型（text/image/audio 等） |
| `output_types`        | 支持的输出类型                        |
| `context_size`        | 上下文窗口大小                        |
| `parameters`          | 参数 JSON Schema                      |
| `parameter_overrides` | 对基础 schema 的覆盖                 |

专属卡片：`ChatModelCard`（`supports_streaming`/`supports_function_calling`/`supports_reasoning` 等）、`EmbeddingModelCard`（`dimensions` 向量维度、`supports_multimodal`）、`TTSModelCard`（`voices`、`sample_rate` 等）。

**模型发现**：`await XxxChatModel.list_models(credential=cred)` 返回可用模型卡片列表——智能体服务的「Schema 驱动前端」正是基于此渲染模型选择表单。

| 类                        | 说明                       |

共享构造参数：

| 参数           | 类型         | 说明                                        |
| -------------- | ------------ | ------------------------------------------- |
| `credential`   | 必填         | 凭证实例                                     |
| `model`        | `str`        | 模型标识                                     |
| `parameters`   | `Parameters` | 模型参数（temperature 等，经 schema 校验）  |

| `context_size` | `int \| None` | 覆盖卡片声明的上下文长度                    |
| `formatter`    | `Formatter`  | 消息格式化器（Chat/MultiAgent）              |

### 直接调用模型（脱离智能体）

```python
import asyncio
import os

from agentscope.credential import DashScopeCredential
from agentscope.message import UserMsg
from agentscope.model import DashScopeChatModel

model = DashScopeChatModel(
    credential=DashScopeCredential(api_key=os.environ["DASHSCOPE_API_KEY"]),
    model="qwen3.7-max",
    parameters={"temperature": 0.7},
)

# 非流式
response = await model([UserMsg("user", "你好")])
print(response.content)

# 流式
async for chunk in model([UserMsg("user", "讲个故事")], stream=True):
    print(chunk, end="")   # is_last=True 的块为累积全文，此前为增量
```

**中断处理**：调用被取消时响应带 `FinishedReason.INTERRUPTED`，已生成内容保留，供上层优雅中断。

**模型级结构化输出**：`await model.generate_structured_output(schema, messages, instructions)` 直接返回校验后的 Pydantic 实例；智能体层的 `structured_schema` 即基于此（见 [智能体 · 结构化输出](智能体.md#结构化输出)）。

## 嵌入模型

| 类                        | 说明              |
| ------------------------- | ----------------- |
| `DashScopeEmbeddingModel` | 阿里云百炼嵌入    |
| `OpenAIEmbeddingModel`    | OpenAI 嵌入       |
| `GeminiEmbeddingModel`    | Google Gemini 嵌入 |
| `OllamaEmbeddingModel`    | Ollama 本地嵌入   |

```python
emb = DashScopeEmbeddingModel(
    credential=DashScopeCredential(api_key=...),
    model="text-embedding-v4",
)

# 批量嵌入：框架自动分批、并发执行、失败批次重试，按原顺序拼接返回
vectors = await emb(["你好", "世界"])
```

多模态嵌入传入 `DataBlock` 或 URL 列表即可。**嵌入缓存**：`embedding_cache=FileEmbeddingCache(path=...)`，相同输入直接命中磁盘缓存，避免重复计费。

## TTS 模型

```python
from agentscope.model import DashScopeTTSModel

tts = DashScopeTTSModel(credential=..., model="cosyvoice-v2")

# 标准合成
response = await tts.synthesize(text="你好，世界！", voice="longwan")
response.audio        # bytes：音频数据
response.media_type   # 如 "audio/wav"
response.usage        # 字符计量
```

实时模式生命周期：`push_text(...)` 多次分段推送 → `synthesize()` 流式产出音频块 → `finish()` 结束，适合边生成边播放的低延迟场景。与智能体集成用 `TTSMiddleware`（见 [中间件](中间件.md#内置中间件)）。

## 自定义模型提供商（三步）

**第 1 步：定义凭证**

```python
from agentscope.credential import CredentialBase

class MyProviderCredential(CredentialBase):
    credential_type = "my_provider"

    def __init__(self, api_key: str) -> None:
        self.api_key = api_key

    async def verify(self) -> None:
        # 调用一个轻量端点验证密钥；失败抛异常
        ...
```

**第 2 步：实现模型类（核心是 `_call_api`）**

```python
from agentscope.model import ChatModelBase, GenerateResponse

class MyProviderChatModel(ChatModelBase):
    model_type = "my_provider"

    async def _call_api(self, messages, tools, tool_choice, **kwargs) -> GenerateResponse:
        # 1. 把 AgentScope 消息转换为你的 API 格式
        # 2. 发起 HTTP 请求（流式时产出 delta）
        # 3. 把响应封装为 GenerateResponse(content=..., usage=...)
        ...
```

**第 3 步：编写 YAML 模型卡片**

```yaml
# 放到 custom_yaml_dir（如 ./models/my_provider/）下
model: my-model-v1
display_name: My Model
provider: my_provider
context_size: 128000
input_types: ["text"]
output_types: ["text"]
parameters:
  type: object
  properties:
    temperature: {type: number, default: 0.7}
```

将 `custom_yaml_dir` 指向卡片目录后，`MyProviderChatModel.list_models(credential)` 即可枚举你的模型；注册到智能体服务（`extra_credentials`）后前端自动展示，见 [CICD集成](../../部署规范/CICD集成.md)。
