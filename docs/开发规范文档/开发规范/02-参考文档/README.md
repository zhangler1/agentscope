## 一次回复的完整数据流

理解下面这条链路，五个模块的分工就清楚了：

```text
① 用户输入构造为 Msg（消息与事件）
        │
② 进入 Agent 的 ReAct 循环（智能体）
        │
③ 每轮推理前：上下文三层组装 + 运行时注入（上下文管理）
   每轮推理调用模型层（模型层）
        │
④ 中间件在 ①②③ 全程拦截（中间件）
        │
⑤ 产出事件流 → 前端消费 / append_event 累积回 Msg（消息与事件）
```
