# 工具 / MCP · 选型指南

> 目标：给智能体扩展行动能力时，知道该用哪条路径。

## 两种扩展能力

| 能力     | 适合场景                                             | 文档                     |
| -------- | ---------------------------------------------------- | ------------------------ |
| **工具** | 自研能力（调内部 API、查数据库）；开箱即用的 11 个内置工具 | [使用工具指南](使用工具指南.md) |
| **MCP**  | 复用现成的 MCP 生态服务（文件系统、搜索、浏览器等）   | [使用工具指南 · MCP 接入](使用工具指南.md#mcp-接入) |

## 决策树

```text
想让智能体执行某种行动？
├── 行动是自己写的代码（调内部系统）？ → 自定义工具（ToolRegistry 注册 / build_enterprise_tools 装配）
├── 生态里已有现成的 MCP server？      → MCP 接入（Stdio / HTTP）
├── 是"教智能体一套做法"而非"给一个函数"？ → 技能（见 ../04-技能/使用技能指南.md）
├── 想让智能体查询公司文档/知识库？     → 知识召回 RAG（见 知识召回.md）
```

## 本目录文档

| 文档 | 内容 |
| ---- | ---- |
| [使用工具指南](使用工具指南.md) | 内置工具 11 个、自定义工具两种加载方式（`ToolRegistry` 自动扫描 / `enterprise.py` 主动 build）、MCP 接入、工具中间件、执行后端切换 |
| [知识召回](知识召回.md) | 行内接口 cross_search 跨知识搜索、参数配置（custom_params）、工具挂载开关、开源 RAG 备选 |

## 三个核心概念

| 概念        | 说明                                                              |
| ----------- | ----------------------------------------------------------------- |
| **工具**    | `ToolBase` 子类，一个可被 LLM 调用的能力单元                      |
| **Toolkit** | 工具箱，统一注册与管理工具、MCP 服务、技能与工具组，并对接权限系统 |
| **工具组**  | `ToolGroup`，按需激活的工具分组；保留组 `basic` 始终在线          |

> **提示**：工具调用受权限系统管控（何时触发人工确认见 [权限系统](../02-agentscope官方参考文档/06-工具/权限系统/概述.md)），实际执行位置由工作区决定（见 [工作区与沙箱](../02-agentscope官方参考文档/07-工作区与沙箱/概述.md)）。
