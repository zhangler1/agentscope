# 知识召回

> 目标：使用行内知识检索接口让智能体查询私有知识库——知道 cross_search 工具何时用、参数怎么填、如何经会话参数接口配置。

## 概述：行内接口 + cross_search

项目的知识召回**不走开源 RAG 链路**（Parser / Chunker / Embedding / VectorStore），而是调用**行内知识检索接口**，由 `cross_search` 工具（跨知识搜索）承载：

- 跨**场景 / 团队 / 个人**知识库混合召回；
- 全文检索 + 向量检索双维度，结果含 rerank 重排；
- 由 `build_enterprise_tools` 装配，**始终挂载**（不受 `vector_search_switch` 等开关控制）。

```python
from bocomadp.tools import build_enterprise_tools

tools = await build_enterprise_tools(user_id, agent_id, session_id)
cross = next(t for t in tools if t.name == "cross_search")   # 始终可用
```

## 工具参数

| 参数 | 说明 | 必填 |
| ---- | ---- | ---- |
| `keyword` | 用户的**完整查询语句**（禁止提取关键词或改写用户输入） | 是 |
| `space_code_list` | 场景知识空间代码列表，如 `["SP0000001", "SP0000002"]` | 三者至少其一 |
| `team_space_code_list` | 团队知识空间代码列表 | 三者至少其一 |
| `psnl_space_code_id` | 个人知识空间代码 | 三者至少其一 |
| `user_code` | 用户编码，通常由系统自动填充 | 否 |
| `search_type` | 搜索类型：`0`=混合检索（默认）、`1`=全文检索、`2`=向量检索 | 否 |
| `customized_tag_list` | 自定义标签列表，用于过滤搜索结果 | 否 |
| `psnl_category_id_list` | 个人知识分类 ID 列表 | 否 |
| `text_top_n` / `vector_top_n` | 全文 / 向量检索返回条数，不传使用配置默认值 | 否 |

> **注意**：至少需要 `space_code_list`、`team_space_code_list`、`psnl_space_code_id` 中的一个，否则检索失败。

## 用户参数：经会话参数接口配置

用户**不需要让模型自行拼空间码**——空间码等参数通过 run 接口请求体的 `custom_params` 字段填写，工具调用时由空间码覆盖中间件**强制生效**（即使模型传错值也会被纠正为请求方指定的值）：

```http
POST /api/deerflow/threads/{thread_id}/runs/stream
Content-Type: application/json
```

```json
{
  "agent_id": "jhzd_lead_agent",
  "session_id": "{thread_id}",
  "input": {
    "messages": [{"type": "human", "content": "查询我行个人手机银行的贷款还款规则"}]
  },
  "custom_params": {
    "space_code_list": ["SP0000001", "SP0000002"],
    "team_space_code_list": ["SP0000003"],
    "psnl_space_code_id": "PER123",
    "user_code": "U10086",
    "search_type": "0",
    "customized_tag_list": ["贷款", "手机银行"],
    "psnl_category_id_list": ["CATE1", "CATE2"]
  }
}
```

`cross_search` 支持从 `custom_params` 强制覆盖的参数键：

`space_code_list`、`team_space_code_list`、`psnl_space_code_id`、`user_code`、`search_type`、`customized_tag_list`、`psnl_category_id_list`

- `personal_search_switch` 显式为 `False` 时，`psnl_space_code_id` / `psnl_category_id_list` 会被清空——等价于禁用个人检索维度；
- 未填写时回退到 `config.yaml` 的 `cross_search` 节点默认值（部署配置见下节）。

> `POST /api/deerflow/threads/{tid}/runs/wait`（阻塞至完成）同样支持 `custom_params`，语义一致。

## 相关工具与挂载开关

知识召回由以下企业工具协作，开关均在 `custom_params` 中显式控制：

| 工具 | 检索范围 | 挂载规则 |
| ---- | -------- | -------- |
| `cross_search` | 跨场景 / 团队 / 个人知识库（知识召回主入口） | **始终挂载** |
| `vector_search` | 行内知识库向量检索（单库） | 默认挂载；`vector_search_switch: false` 时不挂 |
| `online_search` | 联网搜索 | 默认不挂；`online_search_switch: true` 时才挂 |
| `personal_search` | 个人知识库（需空间参数齐备） | `personal_search_switch: true` 且 `tools_param.personalKnowledgeSearch`（`psnlSpaceCodeId` / `psnlCategoryIdList`）齐备时才挂 |

```json
{
  "custom_params": {
    "space_code_list": ["SP0000001"],
    "vector_search_switch": true,
    "online_search_switch": false,
    "personal_search_switch": false
  }
}
```

## 部署配置（config.yaml）

行内接口地址与调用默认值在 `config.yaml` 的 `cross_search` 节点配置（字符串值支持 `$VAR` / `${VAR}` 环境变量引用展开，如 `api_url: $CROSS_SEARCH_API_URL`）：

```yaml
cross_search:
  api_url: https://kb-gateway.internal/searchKnowledgeCross   # 行内检索接口
  caller: bocomadp             # 调用方标识（必填）
  user_code: ""                # 默认用户编码，可被 custom_params 覆盖
  user_role: ""
  search_type: "0"             # 0=混合 1=全文 2=向量
  space_code_list: []          # 默认场景知识空间码
  team_space_code_list: []     # 默认团队知识空间码
  psnl_space_code_id: ""
  text_top_n: 10               # 全文返回条数
  vector_top_n: 10             # 向量返回条数
  rerank_flag: 1
  rerank_top_n: 5
  timeout: 30.0
```

> `api_url` / `caller` 缺失时工具直接报错提示配置；其余字段缺省用代码默认值。生产环境切换域名只需改环境变量，无需改代码。

## 附：开源 RAG 备选（agentscope 原生）

如不使用行内接口，agentscope 框架仍提供原生 RAG 五模块（`Parser` / `Chunker` / `Embedding` / `VectorStore` / `KnowledgeBase`），经 `RAGMiddleware` 接入智能体：

```python
from agentscope.rag import KnowledgeBase, QdrantStore, TextParser
from agentscope.middleware import RAGMiddleware

kb = KnowledgeBase(
    parsers=[TextParser()],
    embedding_model=embedding_model,
    vector_store=QdrantStore(url="http://localhost:6333"),
)

rag = RAGMiddleware(knowledge_base=kb, mode="static", top_k=5)   # 或 agentic
agent = Agent(..., middlewares=[rag])
```

需要自建知识库索引、向量检索时使用；默认场景下**优先使用行内接口的 `cross_search`**。
