## 五大核心模块如何协作

`02-核心概念`（消息/中间件）→ `03-智能体`（Agent 把模型+工具+中间件串成 ReAct 循环）→ `04-模型`（提供推理能力）→ `05-上下文管理`（控制上下文窗口/记忆）→ `06-工具` / `07-工作区与沙箱`（扩展执行与环境）。
