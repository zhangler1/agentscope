# 使用工具指南

> 目标：引入工具包后，用 `ToolRegistry` / `build_enterprise_tools` 两种方式注册自己的工具，MCP 同理。

> **说明**：本文档为对外使用指南，面向**集成方**（引入工具包并扩展自定义工具的使用者）。示例中的包名 `bocomadp_tools` 为占位符，请替换为实际发布的包名。

## 快速开始

安装工具包：

```bash
pip install bocomadp-tools 
```

工具包基于 agentscope 框架，对外提供三个扩展入口：

| 入口 | 作用 |
| ---- | ---- |
| `ToolRegistry` | 工具注册表：注册 / 管理自定义工具（方式一） |
| `build_enterprise_tools` | 企业工具装配**范式**：按会话按需装配（方式二） |
| `McpRegistry` | MCP 注册表：注册外部 MCP 服务（同理） |

最小接入：

```python
from agentscope.tool import Toolkit

from bocomadp_tools import ToolRegistry


# 1. 写一个自己的工具（见「工具的写法」）
# 2. 注册
registry = ToolRegistry()
registry.register(my_tool)

# 3. 注入智能体
toolkit = Toolkit(tools=registry.list_tools())
```

## 内置工具

工具包随 agentscope 框架开箱即用地提供以下内置工具，无需任何开发：

| 工具     | 功能                                   | 权限要点                        |
| -------- | -------------------------------------- | ------------------------------- |
| `Bash`   | 执行 shell 命令                        | 多层安全分析，危险命令触发确认  |
| `Read`   | 读取文件（支持分页 `pages`）           | 只读快速通道                    |
| `Write`  | 写入/新建文件                          | 需先 Read 过目标文件（防盲写）  |
| `Edit`   | 精确替换文件内容（old/new 字符串对）   | 需先 Read 过目标文件            |
| `Glob`   | 按模式匹配查找文件                     | 只读                            |
| `Grep`   | 正则搜索文件内容                       | 只读                            |
| `TaskCreate` / `TaskGet` / `TaskList` / `TaskUpdate` | 计划模式四工具 | 状态注入，直接放行 |
| `GenerateStructuredOutput` | 结构化输出提交      | 直接放行                        |

### Bash 的安全分析

`Bash` 在执行前对命令做多轮静态分析（命令解析、只读分类、危险模式与路径检查、注入风险等），给出「直接放行 / 需要确认 / 直接拒绝」判定。可追加受保护路径：

```python
from agentscope.tool import Bash

bash = Bash(
    additional_dangerous_files=[
        "~/.aws/credentials",   # 追加受保护路径
    ],
)
```

### 文件工具的「先读后写」

`Write` / `Edit` 要求目标文件近期被 `Read` 过，防止智能体盲目覆盖未见过的内容——即使权限模式为 `ACCEPT_EDITS` 也依然生效。

## 方式一：ToolRegistry 注册自定义工具

`ToolRegistry` 是工具注册表：把工具注册进去，`list_tools()` 返回的工具列表可直接注入 `Toolkit`。

### 注册 API

| 方法 | 说明 |
| ---- | ---- |
| `register(tool)` | 注册一个工具；`ToolBase` 实例或裸函数均可，**裸函数自动包装为 `FunctionTool`**，重复注册同名工具自动跳过（幂等） |
| `unregister(name)` | 按名称移除工具 |
| `list_tools()` | 返回全部已注册工具（用于构造 `Toolkit`） |
| `list_tool_names()` | 返回全部已注册工具名 |

### 接入示例

```python
from agentscope.tool import Toolkit

from bocomadp_tools import ToolRegistry

registry = ToolRegistry()
registry.register(weather_tool)      # 注册自己的工具（@tool 函数）
registry.register(MyToolBase())      # 也可注册 ToolBase 实例
registry.unregister("obsolete_tool")  # 按名移除

toolkit = Toolkit(tools=registry.list_tools())
```

包内置工具（`builtin_tools.py` / `custom/` 目录）由包作者通过 `load_builtin_tools()` / `load_custom_tools()` 在包内维护，集成方无需关心；你的扩展一律走 `register()`。

## 方式二：build_enterprise_tools 装配范式

企业工具属于**确定性注入组件**：每次会话运行时显式装配，行为可控、可观测。工具包导出的 `build_enterprise_tools` 即此范式的参考实现，集成方**照同样范式编写自己的装配函数**：

```python
from agentscope.tool import FunctionTool, ToolBase

from bocomadp_tools.tools import get_custom_params  # 会话参数读取


async def build_enterprise_tools(
    user_id: str,
    agent_id: str,
    session_id: str,
) -> list[ToolBase]:
    """返回当前会话可用的企业工具。"""
    params = get_custom_params()   # 会话 custom_params，随任务复制进来
    tools: list[ToolBase] = [
        contact_search_tool,                          # 模块级 FunctionTool 实例
        FunctionTool(query_internal_doc, is_read_only=True),  # 查询类只读
        FunctionTool(submit_it_ticket),
    ]

    # 检索类工具按会话参数显式控制挂载
    if params.get("online_search_switch") is True:
        tools.append(online_search_tool)              # 显式 True 才挂，默认不挂

    if params.get("vector_search_switch") is not False:
        tools.append(vector_search_tool)              # 默认挂载，显式 False 不挂

    return tools
```

范式要点：

- **每会话按需装配**：签名固定为 `(user_id, agent_id, session_id)`，会话参数直接可读；
- **差异化授权**：可按 `user_id` / `agent_id` 决定开放哪些工具（如某些工具只对特定部门开放）；
- **开关控制**：用会话参数（如 `xxx_switch`）显式控制工具挂载，未传时保持默认；
- **只读语义**：查询类工具用 `FunctionTool(fn, is_read_only=True)` 显式包装，保留权限只读快速通道。

装配函数的返回值与 `ToolRegistry` 的工具合并后注入智能体：

```python
from agentscope.tool import Toolkit

from bocomadp_tools import ToolRegistry
from my_app.tools import build_enterprise_tools   # 你的装配函数

registry = ToolRegistry()
registry.register(my_tool)                          # 方式一：全局注册

tools = registry.list_tools()
tools.extend(await build_enterprise_tools(user_id, agent_id, session_id))  # 方式二：会话装配

toolkit = Toolkit(tools=tools)
```

## 两种方式如何选择

| 维度 | 方式一：ToolRegistry | 方式二：build_enterprise_tools 范式 |
| ---- | -------------------- | ----------------------------------- |
| 注册时机 | 启动时一次性注册 | 每次会话运行时装配 |
| 作用范围 | 全局，所有智能体可见 | 仅当前会话，按 user/agent 差异化 |
| 启停控制 | `register` / `unregister` 静态管理 | 会话参数动态开关 |
| 适用场景 | 通用、稳定、无授权差异的工具 | 业务敏感、需授权与开关的企业工具 |

## 工具的写法

无论走哪种方式，工具本体都是三种写法之一。

### @tool 装饰函数（推荐，最常用）

```python
from bocomadp_tools import tool


@tool
def get_current_time() -> str:
    """获取当前日期和时间。

    Returns:
        str: 当前日期和时间，ISO 格式。
    """
    from datetime import datetime

    return datetime.now().isoformat()
```

### FunctionTool 快速包装

无需写类，把普通异步函数快速包装为工具；查询类工具显式声明只读：

```python
from agentscope.tool import FunctionTool

tool = FunctionTool(get_weather, is_read_only=True)
```

### ToolBase 类

适合有状态、需要自定义安全检查的复杂工具：

```python
import httpx

from agentscope.tool import ToolBase


class WebSearch(ToolBase):
    """调用搜索 API 并返回结果摘要。"""

    name = "web_search"
    description = "搜索互联网，返回前 N 条结果的标题与摘要。"
    group = "basic"          # 所属工具组，默认 basic

    parameters = {
        "type": "object",
        "properties": {
            "query": {"type": "string", "description": "搜索关键词"},
            "max_results": {"type": "integer", "default": 5},
        },
        "required": ["query"],
    }

    async def call(self, query: str, max_results: int = 5) -> str:
        async with httpx.AsyncClient() as client:
            resp = await client.get(
                "https://api.example.com/search",
                params={"q": query, "limit": max_results},
            )
            results = resp.json()["results"]
        return "\n".join(f"- {r['title']}: {r['snippet']}" for r in results)
```

`ToolBase` 关键约定：

| 成员                   | 说明                                                          |
| ---------------------- | ------------------------------------------------------------- |
| `name` / `description` | 暴露给 LLM 的工具标识与描述                                   |
| `parameters`           | JSON Schema，约束调用参数                                     |
| `group`                | 所属工具组                                                    |
| `call(...)`            | **子类实现**的执行逻辑                                        |
| `__call__(...)`        | 框架统一调度入口（权限检查 → 执行 → 结果封装），**勿覆写**    |
| `check_permissions`    | 可选：自定义安全检查（见 [输入输出内容审核](../06-安全/输入输出内容审核.md)） |
| `check_read_only`      | 可选：声明工具是否只读（影响权限快速通道）                    |
| `is_external_tool`     | 声明为外部执行工具（见 [智能体 · 外部执行](../02-参考文档/03-智能体.md)） |
| `bypass_immune`        | 安全检查免疫 bypass 模式                                      |

### 工具命名规范

工具名默认使用**中文**（便于行内模型点名），但部分行外 LLM API（如 DeepSeek）强校验工具名 `^[a-zA-Z0-9_-]+$`，中文名会被 400 拒收。工具包提供 `tool_name(cn, en)` 辅助函数，可同时声明中英文名，行外联调时设置环境变量 `BOCOMADP_TOOL_ASCII_NAMES=1` 切换到英文名：

```python
from bocomadp_tools._naming import tool_name

name = tool_name("汇率查询", "exchange_rate")   # 默认中文；ASCII 模式取英文
```

## MCP 接入

MCP 的接入与工具完全同构：`McpRegistry` 对应 `ToolRegistry`，注册后其工具自动对智能体可见。

### 框架层：Toolkit 直接挂载

```python
from agentscope.tool import HttpMCPConfig, StdioMCPConfig, Toolkit

toolkit = Toolkit(
    mcps=[
        # 有状态 · STDIO：子进程长连接
        StdioMCPConfig(
            command="npx",
            args=["-y", "@modelcontextprotocol/server-filesystem", "/data"],
        ),
        # 有状态 · HTTP：远程服务长连接
        HttpMCPConfig(
            url="https://mcp.example.com/mcp",
            headers={"Authorization": "Bearer <token>"},
        ),
    ],
)
```

- **按名筛选**：`StdioMCPConfig(..., enable_tools=["search", "fetch"])` 只导入指定工具；
- **命名空间**：MCP 工具以 `mcp__{server}__{tool}` 形式注册，避免跨服务重名冲突；
- **不经智能体直接调用**：

```python
from agentscope.tool import MCPClient

async with MCPClient(StdioMCPConfig(command=..., args=[...])) as client:
    tools = await client.list_tools()
    result = await tools[0].call({...})
```

无状态模式（短连接、每次调用独立）适合低频调用或服务端不支持长连接的场景。

### 包入口：McpRegistry 注册

工具包提供 `McpRegistry`，与 `ToolRegistry` 同模式的自动发现 + 注册 API：

| 方法 | 说明 |
| ---- | ---- |
| `register(mcp)` | 注册一个 `MCPClient` 实例（带 `name` + `mcp_config`），同名自动跳过 |
| `unregister(name)` | 按名称移除 MCP |
| `list_mcps()` | 返回全部已注册 MCP（传给工作区 `default_mcps` / `Toolkit.mcps`） |

接入示例：

```python
from agentscope.mcp import MCPClient, HttpMCPConfig

from bocomadp_tools import McpRegistry

my_api = MCPClient(
    name="my-service",
    mcp_config=HttpMCPConfig(url="https://my.internal/mcp"),
    is_stateful=False,
)

registry = McpRegistry()
registry.register(my_api)              # 注册自己的 MCP
mcps = registry.list_mcps()
```

带 API key 的 MCP 建议从环境变量读取，避免硬编码。运行在沙箱内的 MCP 需通过工作区网关访问，见 [沙箱 · MCP 网关](../06-安全/沙箱.md#mcp-网关)。

## 工具中间件

拦截每一次工具调用，实现横切逻辑（日志、重试、审计、限流）。洋葱模型，`middlewares` 列表中**第一个在最外层**：

```python
import asyncio
import time

from agentscope.tool import Toolkit, ToolMiddlewareBase


class LoggingMiddleware(ToolMiddlewareBase):
    async def on_tool_call(self, tool, args, call_next):
        start = time.monotonic()
        result = await call_next(tool, args)      # 传递给下一层
        print(f"[{time.monotonic() - start:.2f}s] {tool.name}({args})")
        return result


class RetryMiddleware(ToolMiddlewareBase):
    def __init__(self, retries: int = 2) -> None:
        self.retries = retries

    async def on_tool_call(self, tool, args, call_next):
        for attempt in range(self.retries + 1):
            try:
                return await call_next(tool, args)
            except TransientError:
                if attempt == self.retries:
                    raise
                await asyncio.sleep(2**attempt)


toolkit = Toolkit(
    tools=[...],
    middlewares=[LoggingMiddleware(), RetryMiddleware()],  # 日志在外层
)
```

执行顺序：`Logging → Retry → 工具本体`。

## 执行后端切换

内置文件/命令工具的实际执行位置由**工作区（Workspace）**决定。切换后端只需换工作区实例，工具代码不变：

```python
from agentscope.agent import Agent
from agentscope.tool import Toolkit
from agentscope.workspace import DockerWorkspace

# 所有 Bash/Read/Write 调用都在容器内执行
workspace = DockerWorkspace(base_image="python:3.11-slim")
await workspace.initialize()

agent = Agent(
    name="Friday",
    model=model,
    toolkit=Toolkit(tools=workspace.get_backend()),   # 工作区提供的工具后端
    offloader=workspace,                              # 顺带接管上下文卸载
)
```
