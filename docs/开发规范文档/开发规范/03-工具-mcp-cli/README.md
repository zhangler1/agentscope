# 工具 / MCP / CLI · 选型指南

> 目标：给智能体扩展行动能力时，知道该用哪条路径。

## 三种扩展能力

| 能力     | 适合场景                                             | 文档                     |
| -------- | ---------------------------------------------------- | ------------------------ |
| **工具** | 自研能力（调内部 API、查数据库）；开箱即用的 11 个内置工具 | [使用工具指南](使用工具指南.md) |
| **MCP**  | 复用现成的 MCP 生态服务（文件系统、搜索、浏览器等）   | [使用工具指南 · MCP 接入](使用工具指南.md#mcp-接入) |
| **CLI**  | 开发期零界面调试与事件流渲染                          | [使用工具指南 · CLI 控制台](使用工具指南.md#cli-控制台) |

## 决策树

```text
想让智能体执行某种行动？
├── 行动是自己写的代码（调内部系统）？ → 自定义工具（ToolBase / FunctionTool）
├── 生态里已有现成的 MCP server？      → MCP 接入（Stdio / HTTP）
├── 是"教智能体一套做法"而非"给一个函数"？ → 技能（见 ../04-技能/使用技能指南.md）
├── 想让智能体查询公司文档/知识库？     → 知识召回 RAG（见 知识召回.md）
└── 只是想在终端里调试现有智能体？      → CLI（launch_console / ConsoleRenderer）
```

## 本目录文档

| 文档 | 内容 |
| ---- | ---- |
| [使用工具指南](使用工具指南.md) | 内置工具 11 个、自定义 `ToolBase`、`FunctionTool` 快速包装、工具组按需激活、MCP 接入、工具中间件、执行后端切换、CLI 控制台 |
| [知识召回](知识召回.md) | RAG 五模块（Parser/Chunker/Embedding/VectorStore/KnowledgeBase）、索引与检索、`RAGMiddleware` 双模式、自定义扩展 |

## 三个核心概念

| 概念        | 说明                                                              |
| ----------- | ----------------------------------------------------------------- |
| **工具**    | `ToolBase` 子类，一个可被 LLM 调用的能力单元                      |
| **Toolkit** | 工具箱，统一注册与管理工具、MCP 服务、技能与工具组，并对接权限系统 |
| **工具组**  | `ToolGroup`，按需激活的工具分组；保留组 `basic` 始终在线          |

> **提示**：工具调用受权限系统管控（何时触发人工确认见 [输入输出内容审核](../06-安全/输入输出内容审核.md)），实际执行位置由工作区决定（见 [沙箱](../06-安全/沙箱.md)）。
