# 知识召回（RAG）

> 目标：让智能体查询私有文档/知识库——会用 KnowledgeBase 建索引、做检索，会用 RAGMiddleware 接入智能体，会自定义扩展。

## 五模块架构

AgentScope 的 RAG 由五个可插拔模块组成：

| 模块           | 职责                                |
| -------------- | ----------------------------------- |
| `Parser`       | 把文档解析为文本/多模态内容         |
| `Chunker`      | 切分内容块                          |
| `Embedding`    | 嵌入模型（见 [模型层 · 嵌入](../02-参考文档/模型层.md#嵌入模型)） |
| `VectorStore`  | 向量存储与相似度检索                |
| `KnowledgeBase`| 门面：组合上述模块，提供统一接口    |

## 解析器与切块器

内置解析器（按 `supported_media_types` 路由文件）：`TextParser`、`PDFParser`、`DocxParser`、`PPTParser`、`HTMLParser`、`ImageParser`（多模态，产出 DataBlock）。

默认切块器 `ApproxTokenChunker`：

```python
from agentscope.rag import ApproxTokenChunker

chunker = ApproxTokenChunker(
    chunk_size=512,        # 每块约 512 token
    overlap=50,            # 相邻块重叠，保持语义连贯
)
```

## 向量库

| 向量库              | 可选依赖          | 说明                    |
| ------------------- | ----------------- | ----------------------- |
| `QdrantStore`       | `agentscope[rag]` | Qdrant（本地/集群）     |
| `MilvusLiteStore`   | `agentscope[rag]` | Milvus Lite（嵌入式）   |
| `MongoDBStore`      | `agentscope[rag]` | MongoDB Atlas Vector    |
| `ElasticsearchStore`| `agentscope[rag]` | Elasticsearch 向量检索  |

## KnowledgeBase：索引与检索

```python
from pathlib import Path

from agentscope.rag import (
    ApproxTokenChunker,
    KnowledgeBase,
    PDFParser,
    QdrantStore,
    TextParser,
)

kb = KnowledgeBase(
    parsers=[TextParser(), PDFParser()],
    chunker=ApproxTokenChunker(chunk_size=512),
    embedding_model=embedding_model,
    vector_store=QdrantStore(url="http://localhost:6333"),
    knowledge_root_dir="./kb_data",   # 原始文件与记录的落地目录
)

# 索引：解析 → 切块 → 嵌入 → 写入向量库（一步完成）
await kb.insert_document(
    file_path=Path("handbook.pdf"),
    metadata={"team": "platform", "lang": "zh"},   # 附带元数据
)

# 检索：查询嵌入 → 向量相似度 → 元数据过滤 → 返回 top-K
results = await kb.search(
    query="如何配置权限系统",
    top_k=5,
    metadata_filter={"team": "platform"},   # 多租户深度防御：元数据级隔离
)

for r in results:
    print(r.content, r.metadata, r.score)
```

其余接口：`list_documents()`（列出已索引文档与状态）、`delete_document(doc_id)`（级联清理向量与记录）。

> **提示**：`metadata_filter` 是多租户场景的深度防御——即使向量库被误查，元数据过滤也能保证租户间数据不泄露。

## RAGMiddleware：接入智能体

```python
from agentscope.middleware import RAGMiddleware

# static 模式：每轮用户输入自动检索，命中内容作为 HintBlock 注入
rag = RAGMiddleware(knowledge_base=kb, mode="static", top_k=5)

# agentic 模式：智能体获得 search_knowledge 工具，按需自主检索
rag = RAGMiddleware(knowledge_base=kb, mode="agentic")

agent = Agent(..., middlewares=[rag])
```

两种模式可组合（`mode=["static", "agentic"]`）：常见问题自动注入兜底，深度检索交给智能体判断。

## 自定义扩展

```python
from agentscope.rag import ChunkerBase, VectorStoreBase


class FixedCharChunker(ChunkerBase):
    name = "fixed_char"

    class Parameters(ChunkerBase.Parameters):
        chunk_size: int = 200
        overlap: int = 0

    async def chunk(self, content: str, **params) -> list[str]:
        size, overlap = params["chunk_size"], params["overlap"]
        return [content[i:i + size] for i in range(0, len(content), size - overlap)]


class MyVectorStore(VectorStoreBase):
    """接入自有向量服务：实现 insert/search/delete/list 等接口。"""

    async def insert(self, chunks, vectors, metadata): ...
    async def search(self, query_vector, top_k, metadata_filter): ...
    async def delete(self, doc_id): ...
```

自定义 Parser 同理：继承 `ParserBase`，声明 `supported_media_types`，实现解析方法返回内容块。

## 上生产
