## AgentScope 是什么

AgentScope 2.0 是一个多智能体框架，围绕以下四个设计目标构建：

| 目标 | 落地能力 |
| ---- | -------- |
| **安全** | 权限系统为工具执行提供细粒度门控；human-in-the-loop 确认；工作区（Workspace）提供隔离的执行环境 |
| **高效** | 事件流式输出、上下文自动压缩与卸载、后台任务卸载，长会话与重负载下依然高效 |
| **灵活** | 中间件、模型卡片、工具/技能/MCP 一等公民支持，全部可插拔 |
| **完备** | 从单进程终端调试（控制台）到多租户、多会话、可分布式部署的智能体服务，覆盖开发到生产 |

一句话理解核心抽象：**`Agent` 是一个无状态的推理-行动（ReAct）循环引擎**——所有状态显式存放在 `AgentState` 中，因此天然支持持久化、恢复与多进程部署。

## 第一个智能体

一个最小的智能体由三部分组成：**系统提示词**（身份）、**模型**（大脑）、**工具箱**（手脚）。

```python
import asyncio
import os

from agentscope.agent import Agent
from agentscope.credential import DashScopeCredential
from agentscope.message import UserMsg
from agentscope.model import DashScopeChatModel
from agentscope.tool import Bash, Read, Toolkit, Write


async def main() -> None:
    agent = Agent(
        name="Friday",
        system_prompt="You're a helpful assistant named Friday.",
        model=DashScopeChatModel(
            credential=DashScopeCredential(
                api_key=os.environ["DASHSCOPE_API_KEY"],
            ),
            model="qwen3.7-max",
        ),
        toolkit=Toolkit(tools=[Bash(), Read(), Write()]),
    )

    # 方式一：await 获取最终回复（Msg 对象）
    msg = await agent.reply(UserMsg("user", "介绍一下你自己"))
    print(msg.get_text_content())

    # 方式二：流式消费事件（打字机效果、工具调用过程等）
    async for event in agent.reply_stream(UserMsg("user", "你好！")):
        print(event)


asyncio.run(main())
```

两种运行方式的区别：

- `reply`：阻塞直到智能体完成整轮推理-行动循环，返回最终 `Msg`；
- `reply_stream`：产出细粒度事件流（文本增量、工具调用、思考过程），适合前端集成与实时渲染。

`Toolkit` 中注册的工具受权限系统管控，危险操作会触发确认流程（见 [输入输出内容审核](../06-安全/输入输出内容审核.md)）。

## 零界面调试：终端控制台

开发期不需要 Web 服务，用 `launch_console` 直接在终端对话：

```python
from agentscope.console import launch_console

await launch_console(agent)
# user> 帮我看看当前目录
# 工具确认时按 y 允许一次，a 允许并记住规则，其余拒绝
```

## 核心概念地图

开发任何 AgentScope 应用，你都在组合以下七个概念：

| 概念 | 职责 | 文档 |
| ---- | ---- | ---- |
| `Msg` / `Event` | 对话内容（持久）与运行信号（瞬时） | [消息与事件](../02-参考文档/消息与事件.md) |
| `Agent` | ReAct 循环引擎，一切交互的入口 | [智能体](../02-参考文档/智能体.md) |
| 模型层 | 凭证 + 模型类，9 家 LLM / 嵌入 / TTS | [模型层](../02-参考文档/模型层.md) |
| 工具 / MCP / 技能 | 智能体的行动能力 | [使用工具指南](../03-工具-mcp-cli/使用工具指南.md)、[使用技能指南](../04-技能/使用技能指南.md) |
| 中间件 | 观测、预算、记忆、RAG 等横切能力 | [中间件](../02-参考文档/中间件.md) |
| Workspace | 隔离的执行环境（沙箱） | [沙箱](../06-安全/沙箱.md) |
| 权限系统 | 工具调用的安全门控 | [输入输出内容审核](../06-安全/输入输出内容审核.md) |

它们的关系：

```text
用户输入 (Msg)
   │
   ▼
Agent（ReAct 循环）
   ├── 模型层 ── 推理（受上下文管理约束：压缩/卸载/注入）
   ├── 权限系统 ── 门控工具调用（必要时 HITL 确认）
   ├── 工具/MCP/技能 ── 在 Workspace 沙箱内执行
   └── 中间件 ── 全链路拦截（tracing/预算/记忆/RAG）
   │
   ▼
事件流 (Event) ── 前端消费 / 累积回 Msg
```
