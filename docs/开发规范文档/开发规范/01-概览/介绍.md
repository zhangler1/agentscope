# 介绍

> 目标：快速了解本项目是什么、与官方 AgentScope 的关系、做了哪些企业内部特有的对接与改造，以及整套文档怎么读。

## 一、项目背景

**agentscope bocom（服务名 `agentscope bocom`）** 是基于开源框架 **AgentScope 2.0** 二次封装开发的企业级智能体框架，用于在行内（内网）环境构建、托管和运营面向办公与业务场景的智能体应用。

选择在 AgentScope 之上做二次开发，而不是从零自研，基于三点：

1. **框架能力完备**：AgentScope 原生提供消息与事件流、ReAct 智能体、模型抽象、工具箱、权限系统、工作区与沙箱、Agent 服务化（`create_app` 开箱即得 12 组 REST 路由）等能力，避免重复造轮子；
2. **扩展点清晰**：凭证（`CredentialBase`）、模型（`ChatModelBase`）、工具（`ToolRegistry`）、中间件、技能中心、存储与消息总线等均为可插拔接口，企业私有对接以「注册 + 注入」的方式完成，不侵入框架核心代码；
3. **服务化天然支持**：多租户存储、会话锁、SSE 事件流、K8s 沙箱等生产级能力直接可用，二次开发聚焦在「行内特有对接」而非底层基建；

> 核心原则：**能注册就注册、能装配就装配、能配置就配置**——不 fork 框架、不修改官方代码，企业能力全部通过框架提供的扩展点注入。

### 2.2 工具 / 技能 / 记忆：主包保留机制，企业内部对接独立拆包

工具、技能、记忆三类能力，**框架原生的基础机制在主包中完整保留、随框架开箱即用**（内置工具、`Toolkit` / `ToolRegistry`、MCP 接入、SKILL.md 技能加载、记忆中间件等，见 [06-工具](../02-agentscope官方参考文档/06-工具/概述.md) 与 [05-上下文管理](../02-agentscope官方参考文档/05-上下文管理/长期记忆.md)）。**单独拆出、独立成包发布的，只是企业内部特有的对接实现**（行内系统工具、技能 hub、企业记忆服务），可脱离框架单独安装到其它 AgentScope 工程。`03` / `04` / `05` 三个目录即三个对接包的使用规范：

| 目录 | 主包自带机制（开箱即用） | 独立对接包 | 安装 | 对接包提供的内容 |
| ---- | ---- | ---- | ---- | ---- |
| [03-自定义工具-mcp-cli](../03-自定义工具-mcp-cli/README.md) | 框架内置工具（Bash / Read / Write 等）、`Toolkit` / `ToolRegistry` 注册机制、MCP 接入 | 工具包（`bocomadp-tools`；示例代码中包名 `bocomadp_tools` 为占位符） | `pip install bocomadp-tools` | 行内系统对接工具（HR / Doc / ITSM 等）、`build_enterprise_tools` 装配范式、知识召回 `cross_search` |
| [04-技能](../04-技能/使用技能指南.md) | 框架技能机制（SKILL.md 加载与执行） | 技能包（`skill_hub_sdk`） | `pip install skill_hub_sdk` | 行内技能 hub 对接、技能安装/删除（前端接口、代码直调） |
| [05-记忆](../05-记忆/记忆能力.md) | 框架记忆中间件机制 | 记忆包（`bocomadp.memory`） | — | 行内记忆服务对接、记忆配置 API、程序性/事务性记忆 |

> 三个对接包均基于 AgentScope 扩展点（工具注册表、中间件、路由）实现，与框架是「集成」关系而非「包含」关系；具体用法以对应目录文档为准。

## 三、一次问答的全流程（30 秒版）

了解框架怎么运转，记住「**四条链路**」即可：

```text
配置链路：  创建智能体(POST /agent/) → 创建凭证(POST /credential/) → 创建会话并绑定模型(POST /sessions/)
问答链路：  发消息(POST /chat/，fire-and-forget) → ChatService 后台执行 agent.reply_stream()
事件链路：  MessageBus(Redis) 发布事件 → 前端 GET /sessions/{sid}/stream 的 SSE 长连接回放+实时接收
执行链路：  智能体 ReAct 循环(推理→工具调用→观察) → 工具在沙箱工作区执行 → 权限系统审核 → 继续推理
```

各链路细节见 [快速开始](快速开始.md) 与官方参考文档 [03-智能体](../02-agentscope官方参考文档/03-智能体/概述.md)、[06-工具](../02-agentscope官方参考文档/06-工具/概述.md)。
