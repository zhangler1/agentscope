# 版本

> 目标：了解 AgentScope 2.0 的版本定位与 1.0 的核心差异，做出正确的选型决策。

## 版本结论

- **AgentScope 2.0 与 1.0 不兼容**：这是一次破坏性更新，重新设计了 agent 抽象，API 与 1.0 源码不兼容，且不提供自动迁移路径。
- **新项目一律直接采用 2.0**，以获得事件系统、工作区、权限系统等新版能力；1.0 文档仅供存量用户参考。

## 2.0 与 1.0 核心差异

| 模块 | 主要变化 |
| ---- | -------- |
| 智能体 | `ReActAgent` 重构为 `Agent`；`__call__` 替换为 `reply`/`reply_stream`；hook 机制与 `state_dict`/`load_state_dict` 废弃，改用中间件与 `AgentState`；废弃智能体内 `print` 与 OTel 集成 |
| 事件（新增） | 全新事件系统，服务前端集成与 human-in-the-loop |
| 消息 | 内容块统一继承 Pydantic `BaseModel`；`ImageBlock`/`AudioBlock`/`VideoBlock` 合并为 `DataBlock`；`ToolUseBlock` 更名 `ToolCallBlock` 并新增 `state`/`suggested_rules`；新增 `HintBlock` 与全块 `id`；`Msg` 新增 `created_at`/`finished_at`/`usage`/`append_event`；新增 `UserMsg`/`AssistantMsg`/`SystemMsg` 工厂 |
| 权限（新增） | 工具执行门控、HITL 确认、自治度控制 |
| 工具 | 新增 `ToolBase` 抽象与 `Bash`/`Edit`/`Glob`/`Grep`/`Read`/`Write`/`Task*` 内置工具；`Toolkit` 统一支持工具/技能/MCP/工具组；新增 `ToolGroup`、`ResetTools`、`MCPTool`、`FunctionTool` |
| MCP | 重构为单一 `MCPClient`；新增 `StdioMCPConfig`/`HttpMCPConfig` 声明式配置 |
| 技能（新增） | skill loader 抽象（文件系统/sandbox/web 即时加载）、`LocalSkillLoader`、技能打包为 `ToolGroup` |
| 工作区（新增） | 统一接口提供工具/MCP/技能/上下文 offload；`Local`/`Docker`/`E2B` 等实现无差别切换；`Offloader` 协议；面向多租户的各 `WorkspaceManager`；in-workspace MCP 网关 |
| 模型 | 凭证从模型类解耦为独立模块；支持 Kimi/Moonshot/DeepSeek/xAI/OpenAI Response API；formatter 集成进 chat model；新增 `ModelCard` schema 与 `list_models`；废弃 `Trinity` |
| 中间件（新增） | hook 机制重构为通用中间件系统；`TracingMiddleware` 取代智能体内 OTel |
| 智能体服务（新增） | FastAPI 服务、`create_app` 工厂、lifespan 内各 Manager、`AGUIProtocolMiddleware`/`ToolOffloadMiddleware`、Redis 存储后端 |
| 记忆 | 1.0 memory 模块废弃（与智能体逻辑耦合过深），由长期记忆中间件体系取代 |
| RAG/长期记忆 | 统一到单一模块下，按 2.0 架构持续迭代 |

## 从 1.0 迁移对照速查

| 1.0 写法 | 2.0 写法 | 说明 |
| -------- | -------- | ---- |
| `agent(msg)` | `await agent.reply(msg)` / `agent.reply_stream(msg)` | 入口方法更名并异步化 |
| `agent.state_dict()` / `load_state_dict()` | `AgentState` + 存储后端 | 状态显式化，见 [智能体 · 状态持久化](../02-参考文档/智能体.md) |
| hook 注册 | 中间件装备（`middlewares=[...]`） | 见 [中间件](../02-参考文档/中间件.md) |
| `ToolUseBlock` | `ToolCallBlock` | 更名并扩充字段 |
| `ImageBlock` / `AudioBlock` | `DataBlock`（`media_type` 区分） | 多模态统一 |
| memory 模块 | `AgenticMemoryMiddleware` / `ReMeMiddleware` / `Mem0Middleware` | 见 [检索记忆](../05-记忆/检索记忆.md) |
| model wrapper 传 api_key | `Credential` + 模型类两层结构 | 见 [模型层](../02-参考文档/模型层.md) |

## 环境要求

- Python ≥ 3.11；
- 凭证从环境变量读取（`DASHSCOPE_API_KEY`、`OPENAI_API_KEY`、`E2B_API_KEY` 等），切勿硬编码；
- 需要沙箱执行时按平台准备 Docker / E2B / K8s 等后端，见 [沙箱](../06-安全/沙箱.md)。
