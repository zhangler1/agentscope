# 检索记忆

> 目标：让智能体跨会话"记得"用户与历史——掌握三种长期记忆实现的**检索路径**、注入时机与选型决策。

## 记忆 vs 知识召回（RAG）

开发前先分清两个容易混淆的概念：

| 维度     | 长期记忆                                  | 知识召回（RAG）                          |
| -------- | ----------------------------------------- | ---------------------------------------- |
| 数据来源 | 用户交互中**演化**的偏好、事实、关系      | 静态的文档/知识库                        |
| 写入方式 | 智能体在对话中提取、积累                  | 预先上传、索引                           |
| 典型内容 | "用户偏好中文回复"、"用户负责支付模块"    | 产品手册、内部规范、FAQ                  |
| 详文     | 本文 + [提取记忆](提取记忆.md)            | [知识召回（RAG）](../03-工具-mcp-cli/知识召回.md) |

## 三种实现总览

长期记忆在 AgentScope 中**全部以智能体中间件形式提供**（见 [中间件](../02-参考文档/中间件.md)），装配即生效：

| 实现                      | 存储                     | 检索方式                     | 依赖               |
| ------------------------- | ------------------------ | ---------------------------- | ------------------ |
| `AgenticMemoryMiddleware` | 工作区内的 Markdown 文件 | 异步 LLM 语义检索            | 无（纯本地）       |
| `ReMeMiddleware`          | ReMe 服务                | 混合检索 + 智能体自主读写    | `agentscope[reme]` |
| `Mem0Middleware`          | Mem0 平台                | Mem0 检索 + 工具读写         | `mem0` SDK         |

## 检索路径详解

### AgenticMemory：异步语义检索

记忆以 Markdown 文件存储在 `memory_dir`，`MEMORY.md` 作为索引。每轮对话时，`memory_model` 对用户输入做**语义检索打分**，把相关记忆注入上下文——检索在后台异步进行，**不阻塞主对话**。

```python
from agentscope.credential import DashScopeCredential
from agentscope.middleware import AgenticMemoryMiddleware
from agentscope.model import DashScopeChatModel

memory = AgenticMemoryMiddleware(
    # 独立的记忆模型：检索打分由它完成（可用便宜的小模型）
    memory_model=DashScopeChatModel(
        credential=DashScopeCredential(api_key=...),
        model="qwen3-flash",
    ),
    memory_dir=workspace.workdir / "agentscope" / "memory",
)

agent = Agent(..., middlewares=[memory])
```

检索结果通过中间件钩子注入，智能体无需任何显式调用即可"想起"相关记忆。

### ReMe：混合检索自动注入

```bash
pip install "agentscope[reme]"
```

```python
from agentscope.middleware import ReMeMiddleware

memory = ReMeMiddleware(
    credentials=...,          # ReMe 服务凭证
    mode="both",              # static_control / agent_control / both
    session_scoped=False,     # True 时记忆只在本会话内可见
)
```

| 模式             | 检索行为                                       |
| ---------------- | ---------------------------------------------- |
| `static_control` | 每轮**自动检索**相关记忆注入上下文（框架控制） |
| `agent_control`  | 智能体通过记忆工具**主动检索**                 |
| `both`           | 自动注入 + 智能体可主动查询                   |

### Mem0：双模式检索

```python
from agentscope.middleware import Mem0Middleware

memory = Mem0Middleware(
    # 三种构造方式任选其一：
    model=DashScopeChatModel(...),      # 1. 复用 AgentScope 模型与凭证
    # config={...},                     # 2. mem0 原生 config dict
    # client=mem0_client,               # 3. 已构造的 mem0 AsyncMemory/AsyncMemoryClient
)
```

装配后智能体获得 `search_memory` 工具：按语义检索历史记忆；同时框架提供自动注入，形成"被动注入 + 主动检索"双模式。

## 记忆内容如何进入上下文

记忆检索发生在 `on_reply_start` 阶段（一轮回复开始时），命中内容以系统注入的方式参与上下文组装——这正是三层上下文组装中"摘要/系统层"的可扩展点，详见 [上下文管理](../02-参考文档/上下文管理.md)。

> **提示**：记忆注入同样受 `ContextConfig` 的上下文预算约束，长记忆场景注意配合自动压缩使用。

## 选型建议

```text
需要长期记忆？
├── 不想引入外部服务/依赖？          → AgenticMemoryMiddleware（纯本地文件）
├── 公司已部署 ReMe 服务？           → ReMeMiddleware
└── 团队已使用 Mem0 平台？           → Mem0Middleware
```

记忆如何**写入与维护**（自动提取、显式写入、持久化），见 [提取记忆](提取记忆.md)。
