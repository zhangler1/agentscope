# 会话记忆能力使用规范

## 1. 能力概述

为智能体开启记忆能力后,获得:

| 能力 | 行为 |
| ---- | ---- |
| **记忆检索注入** | 每轮对话开始时,自动以用户输入为查询检索相关记忆,注入模型上下文 |
| **触发式记忆提取** | 满足任一条件时,自动把近期对话提交给记忆服务提取存储: (1)每经过 N 轮对话 (2)会话静默 N 分钟无新对话 |

## 2. 集成步骤

### 2.1 中间件装配

追加记忆中间件:

```python
# main.py
from bocomadp.memory import build_memory_middlewares   # ← 引入记忆中间件

async def _build_agent_middlewares(user_id: str, agent_id: str, session_id: str):
    mws = await build_agent_middlewares(user_id, agent_id, session_id)  # 已有的中间件链
    mws.extend(
        await build_memory_middlewares(user_id, agent_id, session_id)   # 装配记忆中间件
    )
    return mws
```

> 每次组装智能体时自动查询该智能体的记忆配置:`memory_enabled=true` 则挂载记忆中间件,未开启则返回空。

### 2.2 注册记忆配置路由

```python
# main.py
from bocomadp.memory import install_memory

app = create_app(..., extra_agent_middlewares=_build_agent_middlewares)

install_memory(app)   # 注册记忆配置路由
```

## 3. 开启记忆

通过记忆配置接口将 `memory_enabled` 设为 `true` 即完成开启。

```bash
# 第 1 步:查询智能体列表,拿到 agent_id
curl -H "X-User-ID: admin" "http://localhost:8000/api/agent/"

# 第 2 步:开启该智能体的记忆
curl -X PUT "http://localhost:8000/api/memory/config/{agent_id}" \
  -H "X-User-ID: admin" \
  -H "Content-Type: application/json" \
  -d '{"memory_enabled": true}'
```

### 可选参数

以下参数需要调整时通过 `PUT /api/memory/config/{agent_id}` 设置:

| 参数 | 默认值 | 含义 |
| ---- | ------ | ---- |
| `memory_type` | `0` | 记忆类型:`0`=程序性记忆,`1`=事务性记忆 |
| `update_rounds` | `10` | 每 N 轮对话触发一次记忆提取 |
| `memory_prompt` | `""` | 提取提示词,指导"该记什么" |
| `top_k` | `5` | 每次检索召回的记忆条数上限 |

全局参数(`/api/memory/config`), 如需调整:

| 参数 | 默认值 | 含义 |
| ---- | ------ | ---- |
| `idle_minutes` | `15` | 静默触发阈值(分钟) |
| `sweep_interval_seconds` | `60` | 后台扫描间隔(秒) |

## 4. 记忆配置 API

### 4.1 智能体级配置(`/api/memory/config/{agent_id}`)

| 方法 | 说明 |
| ---- | ---- |
| PUT | 增/改记忆配置(部分更新;同步记忆服务) |
| GET | 查看当前记忆配置 |
| DELETE | 删除记忆配置(同步删除记忆服务) |

```bash
# 增/改:开启记忆
curl -X PUT "http://localhost:8000/api/memory/config/{agent_id}" \
  -H "X-User-ID: lwh" -H "Content-Type: application/json" \
  -d '{"memory_enabled": true}'

# 查:查看当前记忆配置
curl -H "X-User-ID: lwh" "http://localhost:8000/api/memory/config/{agent_id}"

# 删:删除记忆配置
curl -X DELETE -H "X-User-ID: lwh" "http://localhost:8000/api/memory/config/{agent_id}"
```

### 4.2 全局配置(`/api/memory/config`)

| 方法 | 说明 |
| ---- | ---- |
| PUT | 增/改全局记忆参数 |
| GET | 查看当前全局记忆参数 |
| DELETE | 删除全局记忆参数(恢复默认值) |

```bash
# 增/改:设置全局记忆配置(有默认值,按需调整)
curl -X PUT "http://localhost:8000/api/memory/config" \
  -H "X-User-ID: admin" \
  -H "Content-Type: application/json" \
  -d '{"idle_minutes": 15}'

# 查:查看当前全局配置
curl -H "X-User-ID: admin" "http://localhost:8000/api/memory/config"

# 删:删除全局配置
curl -X DELETE -H "X-User-ID: admin" "http://localhost:8000/api/memory/config"
```
