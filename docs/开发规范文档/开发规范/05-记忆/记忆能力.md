# 会话记忆能力使用规范

## 1. 能力概述

为智能体开启记忆能力后,获得:

| 能力 | 行为 |
| ---- | ---- |
| **记忆检索注入** | 每轮对话开始时,自动以用户输入为查询检索相关记忆,注入模型上下文 |
| **触发式记忆提取** | 满足任一条件时,自动把近期对话提交给记忆服务提取存储: (1)每经过 N 轮对话 (2)会话静默 N 分钟无新对话 |

## 2. 集成步骤

### 2.1 中间件装配

追加记忆中间件:

```python
# main.py
async def _build_agent_middlewares(user_id: str, agent_id: str, session_id: str):
    mws = await build_agent_middlewares(user_id, agent_id, session_id)  # 已有的中间件链
    mws.extend(
        await build_memory_middlewares(user_id, agent_id, session_id)   # 装配记忆中间件
    )
    return mws
```

> 每次组装智能体时自动查询该智能体的记忆配置:`memory_enabled=true` 则挂载记忆中间件,未开启则返回空。

### 2.2 注册记忆配置路由

```python
# main.py
from bocomadp.memory import install_memory

app = create_app(..., extra_agent_middlewares=_build_agent_middlewares)

install_memory(app)   # 注册记忆配置路由
```

## 3. 参数说明

### 3.1 智能体级参数

| 参数 | 类型 | 默认值 | 含义 |
| ---- | ---- | ------ | ---- |
| `memory_enabled` | bool | `false` | **记忆总开关**。`false` 时其余字段不生效 |
| `memory_type` | int | `0` | **记忆类型**。`0`=程序性记忆,`1`=事务性记忆;作为参数传给记忆服务,决定读写哪一类记忆 |
| `memory_update_rounds` | int | `10` | **轮数触发阈值**。每 N 轮对话触发一次记忆提取;`0`=不按轮数触发(仅靠静默触发) |
| `memory_update_prompt` | str | `""` | **提取提示词**。触发提取时随对话内容一起提交给记忆服务,指导"该记什么",例如"对话中请记住用户的核心偏好与诉求" |

### 3.2 全局参数

通过 `/api/memory/config` 配置(与智能体级 `/api/memory/config/{agent_id}` 同一风格,不带 `{agent_id}` 即全局),修改即时生效。未配置时使用内置默认值。

| 参数 | 类型 | 默认值 | 含义 |
| ---- | ---- | ------ | ---- |
| `idle_minutes` | int | `15` | **静默触发阈值**(分钟)。会话静默超过该时长,自动触发一次记忆提取 |
| `sweep_interval_seconds` | int | `60` | **后台扫描间隔**(秒) |
| `retrieve_top_k` | int | `5` | **检索条数上限**。每次检索最多注入多少条记忆到上下文 |
| `extract_default_window` | int | `100` | **提取窗口**(消息条数)。单次提取最多取最近多少条对话提交给记忆服务 |

## 4. 记忆配置 API

> PUT 支持部分更新:**只传需要修改的字段**,未传字段保持不变;首次设置时未传字段使用默认值。同一接口,带 `{agent_id}` 操作智能体级,不带操作全局。

### 4.1 智能体级配置(`/api/memory/config/{agent_id}`)

| 方法 | 说明 |
| ---- | ---- |
| PUT | 增/改记忆配置 |
| GET | 查看当前记忆配置 |
| DELETE | 删除记忆配置 |

```bash
# 增/改:设置记忆配置
curl -X PUT "http://localhost:8000/api/memory/config/{agent_id}" \
  -H "X-User-ID: lwh" -H "Content-Type: application/json" \
  -d '{
    "memory_enabled": true,
    "memory_type": 1,
    "memory_update_rounds": 5,
    "memory_update_prompt": "对话中请记住用户的核心偏好与诉求"
  }'

# 查:查看当前记忆配置
curl -H "X-User-ID: lwh" "http://localhost:8000/api/memory/config/{agent_id}"

# 删:删除记忆配置
curl -X DELETE -H "X-User-ID: lwh" "http://localhost:8000/api/memory/config/{agent_id}"
```

### 4.2 全局配置(`/api/memory/config`)

| 方法 | 说明 |
| ---- | ---- |
| PUT | 增/改全局记忆参数 |
| GET | 查看当前全局记忆参数 |
| DELETE | 删除全局记忆参数 |

```bash
# 增/改:设置全局记忆配置
curl -X PUT "http://localhost:8000/api/memory/config" \
  -H "X-User-ID: admin" \
  -H "Content-Type: application/json" \
  -d '{
    "idle_minutes": 15,
    "sweep_interval_seconds": 60,
    "retrieve_top_k": 5,
    "extract_default_window": 100
  }'

# 查:查看当前全局配置
curl -H "X-User-ID: admin" "http://localhost:8000/api/memory/config"

# 删:删除全局配置
curl -X DELETE -H "X-User-ID: admin" "http://localhost:8000/api/memory/config"
```
